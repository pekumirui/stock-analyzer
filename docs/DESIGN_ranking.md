# ランキングタブ

決算発表後パフォーマンスの計算は `DESIGN.md` §4.3。共通見た目は `docs/SCREEN_SPEC.md`。

## 誰のための画面か

ある月に決算を出した銘柄のうち、決算後に買って次の決算まで持っていたらどれだけ上がったかを並べて見て、X に共有する自分。

## 画面と遷移

ヘッダーの `ランキング` タブ（`data-tab="ranking"`、ルートは `#ranking`）。中の種類の切り替え `#rk-kind` は今は `決算発表後パフォーマンス` だけ。銘柄名をクリックすると銘柄タブの株価。

## データ形

`GET /api/ranking/earnings-perf` の 1 回分。値は日次バッチが `earnings_events` に入れたもので、表示のたびに株価から計算しない。最初の決算短信かどうか（`is_first`）と発表時刻も日次バッチが入れる。表示のたびに `statements`（重い表）は読まない。

決算は 1 期（銘柄 × 決算期 × 四半期）につき**最初の決算短信の発表日**が起点。後日の訂正は起点にしない。業績予想の修正だけの開示は出さない。決算月はこの起点の日で決める。

## 決算発表後パフォーマンス

**目的。** 選んだ月に決算を出した銘柄を、決算後に買えた値から次の決算の前日終値までのパフォーマンスの高い順に見る。

**要素。** 上から:

1. 種類の切り替え `#rk-kind`（決算速報の 累計 / 3か月 と同じ見た目）
2. 操作の行。決算月 `#rk-month`（`2026年10月決算`、新しい順、最大 36 か月）、`#rk-info`（`N 銘柄 / M/D 終値まで`）、`#rk-share`（`X に投稿`）
3. 表 `#rk-tbl`（`table.sheet`。見た目は共通）。列は左から 順位、銘柄（名前の下に 4 桁コード）、決算日（`M/D`。下段に場中 / 引け後）、パフォーマンス（次の決算の前日終値まで、%）、対TOPIX（%）、終点（`M/D`。次の決算がまだなら `現在`。下段に日数）

次の決算がまだの回は、株価の最終日までの途中の値（`DESIGN.md` §4.3）。

並びはパフォーマンスの高い順。値の無い銘柄（株価がまだ無いなど）は最後。% は正が赤、負が緑。場中 / 引け後の線引きは `DESIGN.md` §4.3。

**操作。** 決算月を選ぶとその月を出す。既定は一番新しい月。銘柄名で銘柄タブの株価へ。

`X に投稿` は表の上位 20 を PNG（横 760px の 2 倍）にする。題は `YYYY年M月決算 決算発表後パフォーマンス 上位N`、その下に期間の説明（`決算後に買えた最初の値から次の決算の前日終値まで（まだなら M/D 終値まで）`）。列と 2 段は表と同じ。名前は半角に寄せ（全角英数字を NFKC）、長ければ `…` で切る。

- スマホ（`pointer: coarse` で画像の共有ができる）: 共有シートに画像と題を渡す。X を選べば画像付きの投稿画面になる
- PC: 画像を保存し、X の投稿画面（`x.com/intent/post`）を題を入れて別タブで開く。画像は保存したものを手で添付する（X の投稿画面の URL では画像を渡せない）

**空とエラー。** 読み込み中は `#rk-info` に `読み込み中…`。月を続けて変えたときは最後の応答だけを出す。決算が 1 件も無ければ `決算のデータがまだありません`。選んだ月に決算が無ければ `この月の決算はありません`。どちらも `X に投稿` を隠す。API 失敗は `読み込みに失敗しました` で表を空にする。

**スマホと PC。** 同じ構造。操作の行は折り返す。表は中身の幅で、足りなければ横スクロール。順位と銘柄は左に固定する。

## API

`GET /api/ranking/earnings-perf?month=YYYY-MM`（省略で一番新しい月。形が違えば 400）

```json
{
  "months": ["2026-10", "2026-09"], "month": "2026-10", "as_of": "2026-10-26",
  "rows": [{"rank": 1, "code": "52460", "name": "ＥＬＥＭＥＮＴＳ",
            "disclosed_date": "2026-10-14", "disclosed_time": "16:00", "session": "after",
            "base_date": "2026-10-15", "base_price": 1150.0,
            "return_to_next": 11.39, "alpha_to_next": 11.07,
            "next_disclosed_date": null, "end_date": "2026-10-26", "days": 12}]
}
```

`session` は `intraday`（場中）/ `after`（引け後）。`as_of` は株価の最終日。データが無ければ `months: []`、`month: null`、`rows: []`。

## 対象外

- 現在まで / +1d / +5d / +20d / +60d への切り替え（今は次の決算までだけ）
- 市場・業種・時価総額での絞り込み
- 決算発表後パフォーマンス以外のランキング
