# ランキングタブ

決算発表後パフォーマンスの計算は `DESIGN.md` §4.3。共通見た目は `docs/SCREEN_SPEC.md`。

## 誰のための画面か

ある月に決算を出した銘柄のうち、決算後に買って次の決算まで持っていたらどれだけ上がったかを並べて見て、X に共有する自分。

## 画面と遷移

ヘッダーの `ランキング` タブ（`data-tab="ranking"`）。中のタブ `#rk-subs`（`.fin-tabs`。`data-rksub="perf|pts"`）は `決算後パフォーマンス`（既定）/ `PTS`。銘柄名をクリックすると銘柄タブの株価。

| 画面 | ルート |
|---|---|
| 決算後パフォーマンス | `#ranking` |
| PTS | `#ranking/pts` |

- 開いたときは決算後パフォーマンス。中のタブを変えても、ほかのタブへ行って戻っても、選んだ中のタブはそのまま
- 再読込は中のタブまで戻す（`ui.route` にも同じパスを残す）
- ヘッダーに PTS タブは無い。古いルート `#pts`（ハッシュと `ui.route`）は `#ranking/pts` に置き換える
- PTS の中身は `docs/DESIGN_pts.md`

## データ形

`GET /api/ranking/earnings-perf` の 1 回分。値は日次バッチが `earnings_events` に入れたもので、表示のたびに株価から計算しない。最初の決算短信かどうか（`is_first`）と発表時刻も日次バッチが入れる。表示のたびに `statements`（重い表）は読まない。

決算は 1 期（銘柄 × 決算期 × 四半期）につき**最初の決算短信の発表日**が起点。後日の訂正は起点にしない。業績予想の修正だけの開示は出さない。決算月はこの起点の日で決める。

## 決算発表後パフォーマンス

**目的。** 選んだ月に決算を出した銘柄を、決算後に買えた値から次の決算の前日終値までの上昇率または下落率で並べて見る。

**要素。** 上から:

1. 種類の切り替え `#rk-kind`（決算速報の 累計 / 3か月 と同じ見た目）。`上昇率`（既定）/ `下落率`
2. 操作の行。決算月 `#rk-month`（`2026年10月決算`、新しい順、最大 36 か月）、`#rk-info`（`N 銘柄 / M/D 終値まで`）、`#rk-share`（`X に投稿`）
3. 表 `#rk-tbl`（`table.sheet`。見た目は共通）。列は左から 順位、銘柄（先頭 5 文字。`title` に正式名。下に 4 桁コード）、市場（月次と同じ `東証P` / `東証S` / `東証G` と色の点。`fmtMarket`）、業種（月次と同じく 33 業種の末尾の `業` を外して先頭 5 文字。`title` に正式名。`fmtSector`）、騰落率（見出しは `騰落率` の下に小さく `(対TOPIX)`。各行は次の決算の前日終値まで %、下段は小さく `(+x.x%)` だけ）、決算日（`M/D`。下段に場中 / 引け後）、経過日数（次の決算がまだなら `N日`＝決算日の翌営業日から終点までの営業日数。終わっていれば `〜M/D`＝次の決算の前日。営業日は TOPIX の日足の日。`保有中` は出さない）

次の決算がまだの回は、株価の最終日までの途中の値（`DESIGN.md` §4.3）。

上昇率は `return_to_next > 0` を高い順。下落率は `return_to_next < 0` を小さい順（最下位は符号が逆転する手前）。0 と欠測はどちらにも出さない。% は正が赤、負が緑。場中 / 引け後の線引きは `DESIGN.md` §4.3。API は月の全件を高い順で返す。タブはクライアントで分ける。

**操作。** 決算月を選ぶとその月を出す。既定は一番新しい月。上昇率 / 下落率は取り直さず同じ応答を塗り替える。銘柄名で銘柄タブの株価へ。

`X に投稿` は表の上位 20 を PNG（横 760px の 2 倍）にする。投稿文は 3 行。画像の題は 1 行目だけ（計測方法の 2 行は投稿文にあるので画像には書かない）:

```
YYYY年M月決算 上昇率ランキングTOPN
計測方法は決算発表後初値〜
※場中決算は翌営業日初値
```

下落率のときは題が `下落率ランキングTOPN`。列と 2 段は表と同じ（列名の下に `(対TOPIX)`、各行の下段は括弧の % だけ）。名前は半角に寄せ（全角英数字を NFKC）、長ければ `…` で切る（画面の 5 文字切りはしない）。

- スマホ（`pointer: coarse` で画像の共有ができる）: 共有シートに画像と投稿文を渡す。X を選べば画像付きの投稿画面になる
- PC: 画像を保存し、X の投稿画面（`x.com/intent/post`）を投稿文を入れて別タブで開く。画像は保存したものを手で添付する（X の投稿画面の URL では画像を渡せない）

**空とエラー。** 読み込み中は `#rk-info` に `読み込み中…`。月を続けて変えたときは最後の応答だけを出す。決算が 1 件も無ければ `決算のデータがまだありません`。選んだ月に決算が無ければ `この月の決算はありません`。選んだ向きの行が無ければ `この月の上昇率はありません` / `この月の下落率はありません`。空のときは `X に投稿` を隠す。API 失敗は `読み込みに失敗しました` で表を空にする。

**スマホと PC。** 同じ構造。操作の行は折り返す。表は中身の幅。足りなければ横スクロール。順位と銘柄は左に固定する（横に送ると市場・業種は銘柄の下に隠れ、騰落率以降が見える）。

## PTS

夜間 PTS ランキング。目的・要素・操作・空とエラー・スマホと PC・API は `docs/DESIGN_pts.md`。このタブの中のタブで出す。日付・値上がり / 値下がり / 出来高・取得時刻・サマリー・表の DOM id は変えない。

## API

`GET /api/ranking/earnings-perf?month=YYYY-MM`（省略で一番新しい月。形が違えば 400）

```json
{
  "months": ["2026-10", "2026-09"], "month": "2026-10", "as_of": "2026-10-26",
  "rows": [{"rank": 1, "code": "52460", "name": "ＥＬＥＭＥＮＴＳ",
            "disclosed_date": "2026-10-14", "disclosed_time": "16:00", "session": "after",
            "base_date": "2026-10-15", "base_price": 1150.0,
            "return_to_next": 11.39, "alpha_to_next": 11.07,
            "next_disclosed_date": null, "end_date": "2026-10-26", "bdays": 8,
            "market": "グロース", "sector33": "情報・通信業"}]
}
```

`session` は `intraday`（場中）/ `after`（引け後）。`as_of` は株価の最終日。データが無ければ `months: []`、`month: null`、`rows: []`。

## 対象外

- 現在まで / +1d / +5d / +20d / +60d への切り替え（今は次の決算までだけ）
- 市場・業種・時価総額での絞り込み
