# 月次

小売・外食・サービス業などの月次売上・客数・客単価・店舗数の推移を、発行体一覧と会社別の年比較グラフ・横スクロール表で確認する画面の仕様を定める。個人用 SPA（`/app` の `#tab-monthly`）と一般公開ページ（`https://kabukpi.com/monthly`）が同じ見た目とフロントエンド実装（`static/js/monthly.js`）を共有する。

取込と暦年割当の規則は [月次の取込規則](../jobs/monthly.md)、保存名の正規化と凍結規則は [月次の行名](../jobs/monthly_labels.md)、画面が呼ぶ API とテーブルの対応図は [画面設計: 月次](gen/monthly.md)、共通の見た目とテーブル規約は [画面仕様の共通規則](SPEC.md)、API の共通規約は [API 仕様](api.md) を参照する。

## 誰のための画面か

小売・外食・専門店などの月次開示（全店・既存店の売上前年比、客数・客単価、出退店・店舗数）を会社ごとに追いたい投資家のための画面である。公開面（`/monthly`）は Basic 認証なしで検索エンジンや外部リンクから直接開けるようサーバー側で初期 HTML も描画し、個人ツール（`/app`）では他タブと並ぶ `月次` タブとして同じ UI を提供する。

## 画面と遷移

画面は発行体を一覧する **TOP** と、1 社の複数年データを表示する **Detail** の 2 画面で構成する。

個人ツール（`/app`）と公開面（`/monthly`）の URL・戻り導線の対応は以下のとおりである。

| 画面 | `/app` のハッシュ | 公開面のパス | 表示切替と戻り操作 |
|---|---|---|---|
| TOP | `#monthly` | `/monthly` | `#monthly-top` を表示し、`#monthly-detail` を隠す。トップ画面のためパンくずは出さない |
| Detail | `#monthly/{code5}`（5 桁コード、例: `#monthly/99830`） | `/monthly/{code4}`（4 桁コード、例: `/monthly/9983`） | `#monthly-detail` を表示し、`#monthly-top` を隠す。`/app` ではパンくず `#crumb`（`月次 > {社名}`）、公開面では `#monthly-back`（`← 一覧`）またはヘッダーの `月次データ` リンクで TOP へ戻り、直前に選んでいたチップと確定済み検索語を維持する |

## データ形

DB は縦持ちの 4 テーブル（`monthly_issuers`・`monthly_tables`・`monthly_elements`・`monthly_values`、詳細は [データモデル](../SCHEMA.md)）でセルを保持し、`(code, year, element, month)` で 1 つの月次セルを一意に表す。公表日は別表 `monthly_publications`（銘柄 × 暦年 × 月）にあり、この画面の GET には出さない。`month` は公表対象の暦月 `1`〜`12`、`year` はその月が属する暦年である（会計年度から暦年への変換規則は [月次の取込規則](../jobs/monthly.md) を参照する）。

各行が持つ単位 `unit` と画面上の数値表記の対応は以下のとおりである。

| `unit` | DB 上の保持値 | 画面上の表示形式 |
|---|---|---|
| `yoy_index` | 前年同月 = `100` の指数（例: `103.2`） | 小数第 1 位までの指数（`103.2`）をそのまま出し、`%` は付けない |
| `yoy_pct` | 前年同月比の増減率（例: `+3.2%` は `3.2`） | `100 + v` の指数（`103.2`）に換算して出し、開示元ごとの表記差を吸収する |
| `rate` | 前年比ではない比率（粗利率・稼働率・解約率・EC 化率など） | 数値の末尾に `%` を付けて出す（例: `51.6%`） |
| `number` | 実数（売上高・客数・店舗数・件数など） | 整数は 3 桁カンマ区切り、小数は末尾の不要な `0` を除いて出す |

行名からの系列分類（`monthly_series_kind`）、TOP の代表値選択、新着判定、業種分類の規則は以下のとおりである。

| 分類・属性 | 判定規則 |
|---|---|
| `all_store`（全店前年比） | 行名に `全店` または `全社` を含み `既存` を含まない行、またはスコープ無しの `売上高`・`連結売上高`・`客数`・`客単価` 行のうち、内訳（`breakdown`）が無く、`会員数` を含まず（#366）、指標種別が `other`・`count`（売上総利益・売上個数等）ではなく、`unit` が `yoy_index` または `yoy_pct` の行とする |
| `existing_store`（既存店前年比） | 行名に `既存` を含み、内訳が無く、`会員数` を含まず、指標種別が `other`・`count` ではなく、`unit` が `yoy_index` または `yoy_pct` の行とする |
| `store_count`（店舗数） | 行名に `店舗数` を含み、フロー・調整語（`出店`・`退店`・`純増`・`新設`・`改装`・`業態転換` 等）を含まず、`unit` が `number` の行とする |
| TOP の代表前年比セル | `all_store`・`existing_store` それぞれについて、グループ・セグメント・国・チャネル・内訳がすべて空で指標が `売上高` または `連結売上高` の会社全体行（優先段 0）を最優先し、会社全体行が無い会社でのみ客数・客単価やセグメント付き行（優先段 1）を使う。同一優先段内では値がある最大の `(year, month)`、同月なら `sort_order` 昇順・`element` 昇順で 1 行を選ぶ |
| `ingested_today` と `is_new` | `monthly_tables.updated_at` が JST 当日 0:00 以降なら `ingested_today: true`（`NEW` バッジ対象）、JST 前日 0:00 以降なら `is_new: true`（`新着` チップ対象。夜間更新分を翌日いっぱい拾えるようにする）とする |
| `industry`（月次業種） | 東証 33 業種（多くが `小売業` に集まる）とは別に、`monthly_issuers.industry` で外食・アパレル・ドラッグストア等を管理する。空文字または未設定は `未分類` とする |

## TOP

### 目的

月次データを収録している発行体を新着・業種・社名検索で絞り込み、最新月の全店・既存店前年比を見比べて目的の会社を開く。

### 要素

`#monthly-top` 上部に検索フォーム `#monthly-search-form`（入力 `#monthly-q`、`検索` ボタン、入力中または確定語があるときのみ表示するクリアボタン `#monthly-q-clear` `×`）を置き、その下にチップ列 `#monthly-groups`、本体に `#monthly-list` 内のテーブル `#monthly-tbl`（`table.sheet`）を置く。

チップ列 `#monthly-groups` の構成と初期選択は以下のとおりである。

| 面 | チップの並び順 | 初期選択チップ |
|---|---|---|
| 公開面（`/monthly`） | `すべて`（`__all__`）→ `新着`（`__new__`）→ 1 社以上属する `industry`（日本語ロケール順） | `すべて` を選ぶ |
| 個人ツール（`/app`） | `新着`（`__new__`）→ 1 社以上属する `industry`（日本語ロケール順） | `is_new: true` の会社が 1 社以上あれば `新着` を選び、0 社のときは先頭の `industry` チップを選ぶ |

`#monthly-tbl` は以下の 5 列で構成する。初期行順は `is_new: true` の会社が先、同じなら `latest_ym` の降順、さらに同じなら `code` の昇順である。

| 列名 | `data-msort` | 表示内容 |
|---|---|---|
| `会社名` | `code` | 4 桁コード + 半角スペース + 社名の先頭 5 文字（例: `9983 ファースト`）を 1 行で出し、`ingested_today: true` の会社には右に `NEW` バッジ（`span.badge.new`）を添える |
| `業種` | `industry` | `monthly_issuers.industry`（未設定は `未分類`）を出す |
| `最新月` | `latest_ym` | 値が入っている最大の `(year, month)` を `YYYY-MM` で出す（値が無ければ空欄） |
| `全店(前年比)` | `all_store_yoy` | 全店代表行の最新値を指数（例: `103.2`）で出す。該当系列が無い会社は `-` を出す |
| `既存店(前年比)` | `existing_store_yoy` | 既存店代表行の最新値を指数で出す。該当系列が無い会社は `-` を出す |

### 操作

`#monthly-groups` のチップを押すと、対象の発行体だけで表を即座に描き直す。

検索は 1 文字ごとのインクリメンタル絞り込みを行わず、`Enter` キーまたは `検索` ボタン（フォームの `submit`）で確定する。確定した検索語がある間は選択中のチップに関わらず全発行体を対象に、NFKC 正規化・小文字化・ひらがな→カタカナ変換を通した社名部分一致またはコード部分一致（4 桁・5 桁）で絞り込む。`#monthly-q-clear`（`×`）を押すと検索語を解除してチップ絞り込みへ戻る。

列見出し `th[data-msort]` を押すとソートが切り替わる。文字の列（`code`・`industry`）は昇順→降順→解除、月・数値の列（`latest_ym`・`all_store_yoy`・`existing_store_yoy`）は降順→昇順→解除の順で回り、欠損値は常に末尾へ送る。

一覧の行を押すと Detail へ遷移する。公開面の行内リンク `<a href="/monthly/{code4}">` は通常クリック時に `history.pushState` で画面遷移し、`Ctrl` キーや `Cmd` キーを押しながらのクリックでは別タブで開く。

### 空とエラー

TOP における欠損セル・0 件・エラー時の表示は以下のとおりである。

| 状態 | 表示先と文言 |
|---|---|
| `全店(前年比)` または `既存店(前年比)` に該当系列が無い | 該当セルに `-` を出す |
| 登録発行体が 0 件、選択チップの対象が 0 件、または `GET /api/v1/tables` が失敗 | 表を出さず、`#monthly-list` に `登録された月次データはありません` を出す |
| 確定した検索語に一致する発行体が 0 件 | 表を出さず、`#monthly-list` に `該当する発行体はありません` を出す |
| 公開面で未登録コードの `/monthly/{code4}` を直接リクエスト（`404`） | TOP 枠内に `発行体が見つかりません。` を出す |

### スマホと PC

`#monthly-tbl` の `会社名` 列は PC のみ左端 `sticky` とし、スマホ（`640px` 以下）では解除して 5 列全体を横スクロールできるようにする。

## Detail

### 目的

1 社の月次データについて、最新年と前年の 1〜12 月比較グラフと、収録全期間を時系列で並べた横スクロール表（および事業・業態階層がある会社の親子木表示）を確認する。

### 要素

`#monthly-detail` 上部に公開面のみ表示する戻るボタン `#monthly-back`（`← 一覧`）と、社名見出し `#monthly-title`（`{正式社名} {4桁コード}`、例: `ファーストリテイリング 9983`）を置く。

その下に系列選択バー `#monthly-series-bar`（`<select id="monthly-series">`）、グラフ枠 `#monthly-chart-wrap`（SVG `#monthly-chart` とツールチップ `.monthly-tip`）、木表示切替バー `#monthly-view-bar`、および横スクロール表 `#monthly-table-wrap`（`table.sheet.monthly-tl`）を順に並べる。

系列選択と年比較グラフ `#monthly-chart` の仕様は以下のとおりである。

| 要素 | 表示と選択規則 |
|---|---|
| `#monthly-series` | 収録全年を通じて値が 1 つ以上ある全行を並べる。既定の選択は (1) グループ・セグメント・国・内訳が空でスコープが `全店`・`全社`・空のいずれかである `売上高` の前年比行 → (2) `group` 付きを含む同条件の `売上高` 前年比行 → (3) `series_kind == "all_store"` の行 → (4) 先頭行、の優先順で決める（`海外 売上高(前年比)` など国付きの行は会社全体扱いしない） |
| `#monthly-chart`（`yoy_index`・`yoy_pct`） | 横軸に `1月`〜`12月`（スロット幅 `28px` 未満では `1`〜`12`）を固定し、最新暦年（濃い青 `#2c6bed` 実線）と前年（薄い青破線）の最大 2 本の折れ線とデータラベル、および `100` の基準破線を描く |
| `#monthly-chart`（`rate`） | `100` の基準線を引かず、`%` 単位の縦軸で最大 2 年分の折れ線を描く |
| `#monthly-chart`（`number`） | 各月に前年（左・薄色）と最新年（右・濃色）を並べた縦棒グラフを描く（正負混在時は `0` 基準線を実線で引く） |
| `.monthly-tip` | グラフ上のホバーまたはタップ時にハイライト帯とともに出し、各年の値（欠損年は `—`）と、両年に値がある月の前年差（指数・率は `+X.Xpt`、実数は `前年比 XX.X%`）を表示する |

横スクロール表 `table.sheet.monthly-tl` と年比較ポップアップ `#monthly-pop` の仕様は以下のとおりである。

| 項目 | 表示・整列規則 |
|---|---|
| 時間軸の列構成 | 左端に `項目` 列（`.tl-corner`・`td.tl-name`）を固定し、その右に値が存在する最初の月から最新月までを古い月→新しい月の順で横に並べる。上段ヘッダーは年単位の `colspan` で `{YYYY}年`、下段ヘッダーは `{M}月` とし、年が切り替わる最初の月の左に縦罫線 `.tl-ysep` を引く。描画直後は最新月が見える右端へ横スクロール位置を合わせる（#434） |
| フラット表の行順 | `monthlyRowOrder`・`union_monthly_elements` により、セグメント無し（会社全体）のブロックを先頭に置き、続けてセグメント（`group` + `segment`）ごとのブロックを初出順に並べる。各ブロック内は国・チャネル（会社全体→国内→海外）→ 指標スロット（`売上高` → `客数` → `客単価` → `出店` → `退店` → `純増・改装等` → `店舗数` → `件数` → `率` → `その他`）→ 内訳（合計が先、内訳が後）→ スコープ（`全店` → `全社` → `既存` → その他）→ 単位（実数が先、前年比が後）の順で整列する。全期間で値が 1 つも無い行は除外する |
| 前年比ヒート色 | `yoy_index`・`yoy_pct` 行の数値セルには `100` からの乖離に応じた背景色を塗る。`100` 超は赤 `rgba(211, 47, 47, α)`、`100` 未満は緑 `rgba(27, 138, 90, α)`、`100` ちょうどは無色とし、`α` は乖離幅 `20pt` で上限 `0.36` に達する線形スケールとする |
| 年比較ポップアップ `#monthly-pop` | 月セル `td.num[data-m]` を押すと、その行の同じ月について `2024` 年以降（`MONTHLY_POPUP_MIN_YEAR = 2024`、それ以前は取込済みと未取込が混在するため対象外）の各暦年の値を縦に並べた `#monthly-pop` をセル付近に表示する |

#### 親子関係

事業・業態・地域・商品などの階層構造を持つ発行体では、表の左上に切替バー `#monthly-view-bar` を表示する（階層を持たない単一事業の発行体では `#monthly-view-bar` を出さない）。

| 項目 | 構築・表示規則 |
|---|---|
| モード切替と指標タブ | 左端の `#monthly-mode-seg` で `一覧`（既定のフラット表）と `親子関係`（木表示）を切り替える。`親子関係` を選んでいる間は右隣に指標タブ `#monthly-metric-tabs` を出し、その発行体に値がある指標だけを `全店 売上高(前年比)` → `既存店 売上高(前年比)` → `全店 客数(前年比)` → `既存店 客数(前年比)` → `全店 客単価(前年比)` → `既存店 客単価(前年比)` → `売上高` → `客数` → `店舗数` の順で並べる（#577・#590） |
| 木の行表示と開閉 | 選択中の 1 指標について親子木の深さ優先順で行を並べ、深さに応じて `td.tl-name` の左パディングを増やす。選択指標の値を持たない中間見出し節はセルを空欄にしたまま `.tl-sec-node` で太字表示し、子を持つ節の左には開閉ボタン `.tl-tw`（展開 `▾`・折りたたみ `▸`、初期状態は全展開）を置く |
| 手書き木（`ISSUER_TREES`） | 多階層の発行体（`30860` J.フロント・`30990` 三越伊勢丹・`33820` セブン＆アイ・`75320` PPIH・`82670` イオン・`98310` ヤマダ・`99830` ファーストリテイリング等、`app/monthly/tree.py`）は各節の `match` 条件で要素を割り当て、未一致の行は末尾の `その他`（既定折りたたみ）にまとめる（#578・#579・#580・#581） |
| 自動木（`build_auto_tree`） | 手書き定義が無い発行体は行名の構造（`group`・`segment`・`country`・`channel`・`breakdown`）から自動で木を組み（#591）、深さ 2 以上または同一親の子が 2 つ以上ある会社にのみ `tree` を返す。`出退店` や `店舗数` にだけ地域内訳がある会社では、該当指標タブにのみ地域木 `tree_metric_parent` を適用して他タブに空見出しを出さない（#592） |

### 操作

`#monthly-series` の選択変更、または表のデータ行 `tr[data-series]` のクリックで対象系列が切り替わり、グラフ `#monthly-chart` が更新される。月セル `td.num[data-m]` を押すと、行の系列切替と同時に年比較ポップアップ `#monthly-pop` が開く（同じセルの再クリック、`×` ボタン、ポップアップ外のクリック、`Escape` キー、または表の横スクロールで閉じる）。

`#monthly-view-bar` がある会社では、`一覧` と `親子関係` の切り替え、指標タブの選択、`.tl-tw` による子孫行の折りたたみ・展開を行える。選択状態はその銘柄を開いている間維持し、別銘柄へ遷移したときに初期化する。

### 空とエラー

Detail における空データ・欠損値・エラー時の表示は以下のとおりである。

| 状態 | 表示先と文言 |
|---|---|
| `GET /api/v1/tables/{code}` が失敗、または収録年が 0 件 | 系列バー・グラフ・切替バーを隠し、`#monthly-table-wrap` に `月次データはまだ登録されていません` を出す |
| 選択した系列に有効な数値が 1 つも無い | SVG を隠し、`#monthly-chart-wrap` に `この系列のデータはありません` を出す |
| 個別の月に値が無い | 横スクロール表 `table.monthly-tl` のセルは空欄（空文字）とし、`#monthly-pop` および公開面の初期 SSR 表では `-`、グラフのツールチップ `.monthly-tip` では `—` を出す |

### スマホと PC

横スクロール表 `table.monthly-tl` の左端 `項目` 列は、PC（幅 `18em`）・スマホ（`640px` 以下、幅 `12em`）の両方で `position: sticky; left: 0` により左固定したまま月列を横スクロールできる。グラフ `#monthly-chart` は `ResizeObserver` でコンテナ幅に追従して再描画し、スマホ（`640px` 以下）では高さを `230px`（PC は `250px`）、軸ラベル文字を `13px`（PC は `11px`）にする。

## API

月次エンドポイントの一覧と共通規約は [API 仕様](api.md)「月次データ（`/api/v1/tables`）」、JS と DB テーブルの対応図は [画面設計: 月次](gen/monthly.md) を参照する。

| エンドポイント | 用途とアクセス制御 |
|---|---|
| `GET /api/v1/tables` | TOP 用に全発行体の要約 `{issuers: [{code, name, industry, latest_ym, is_new, ingested_today, all_store_yoy, existing_store_yoy}]}` を返す。`data_versions['monthly']` に基づく `ETag`（未変更時は `304`）を付ける |
| `GET /api/v1/tables/{code}` | 発行体の収録暦年一覧 `{code, years: [2024, 2025, …]}` を昇順で返す（4 桁・5 桁コード対応、未登録は `404`） |
| `GET /api/v1/tables/{code}/{year}` | 1 社 1 暦年の `{code, year, elements, tree, tree_metrics}`（自動木の場合は `tree_auto` と `tree_metric_parent` を含む）を返す。各要素は `label`（`display`・`metric`・`scope`・`group`・`segment`・`country`・`channel`・`breakdown`・`series_kind` 等）と `values`（`"1"`〜`"12"` の辞書）を持つ |
| `GET /api/v1/tables/{code}/{year}/doc` | 保存済みの開示テキストメモ `{code, year, text}` を返す（画面 JS からは呼ばず運用・MCP 用） |
| 書込系 `/api/v1/tables/…`（`POST`・`PUT`・`DELETE`） | 取込 `POST /ingest`、業種設定 `PUT /industry`、要素・値・メモの更新 API はすべてループバック接続専用（`forbid_proxied_monthly_write`）であり、リバースプロキシ経由（`X-Forwarded-For` 等あり）では `403` を返す |

## 対象外

以下の項目は本画面の対象外とする。

1. ブラウザ画面からの月次データの追加・編集・削除・業種変更は行わない（更新はすべてバッチまたはローカル・MCP 経由で行う）。
2. 複数の発行体を 1 枚のグラフに重ねて比較する機能は置かない。
3. 会計年度順（期首月始まり）の列並びは扱わず、すべて公表対象の暦年・暦月（`1`〜`12`）に統一する。
