# 月次

小売・外食・サービス業などの月次売上・客数・客単価・店舗数の推移を、発行体一覧と会社別の年比較グラフ・横スクロール表で確認する画面の仕様を定める。個人用 SPA（`/app` の `#tab-monthly`）と一般公開ページ（`https://kabukpi.com/monthly`）が同じ見た目とフロントエンド実装（`static/js/monthly.js`）を共有する。

取込と暦年割当の規則は [月次の取込規則](../jobs/monthly.md)、保存名の正規化と凍結規則は [月次の行名](../jobs/monthly_labels.md)、画面が呼ぶ API とテーブルの対応図は [画面設計: 月次](gen/monthly.md)、共通の見た目とテーブル規約は [画面仕様の共通規則](SPEC.md)、API の共通規約は [API 仕様](api.md) を参照する。

## 誰のための画面か

小売・外食・専門店などの月次開示（全店・既存店の売上前年比、客数・客単価、出退店・店舗数）を会社ごとに追いたい投資家のための画面である。公開面（`/monthly`）は Basic 認証なしで検索エンジンや外部リンクから直接開けるようサーバー側で初期 HTML も描画し、個人ツール（`/app`）では他タブと並ぶ `月次` タブとして同じ UI を提供する。

## 画面と遷移

画面は発行体を一覧する **TOP** と、1 社の複数年データを表示する **Detail** の 2 画面で構成する。

個人ツール（`/app`）と公開面（`/monthly`）の URL・戻り導線の対応は以下のとおりである。

| 画面 | `/app` のハッシュ | 公開面のパス | 表示切替と戻り操作 |
|---|---|---|---|
| TOP | `#monthly` | `/monthly` | `#monthly-top` を表示し、`#monthly-detail` を隠す。トップ画面のためパンくずは出さない |
| Detail | `#monthly/{code5}`（5 桁コード、例: `#monthly/99830`） | `/monthly/{code4}`（4 桁コード、例: `/monthly/9983`） | `#monthly-detail` を表示し、`#monthly-top` を隠す。パンくず `#crumbs`（`月次 > {社名}`）、`#monthly-back`（`戻る`）、または公開面ヘッダーのサイト名リンクで TOP へ戻り、直前に選んでいたチップと確定済み検索語を維持する |

## データ形

DB は縦持ちの 4 テーブル（`monthly_issuers`・`monthly_tables`・`monthly_elements`・`monthly_values`、詳細は [データモデル](../SCHEMA.md)）でセルを保持し、`(code, year, element, month)` で 1 つの月次セルを一意に表す。公表日は別表 `monthly_publications`（銘柄 × 暦年 × 月）にあり、一覧の `latest_publication` として銘柄ごとに 1 件だけ載せる。`month` は公表対象の暦月 `1`〜`12`、`year` はその月が属する暦年である（会計年度から暦年への変換規則は [月次の取込規則](../jobs/monthly.md) を参照する）。

各行が持つ単位 `unit` と画面上の数値表記の対応は以下のとおりである。

| `unit` | DB 上の保持値 | 画面上の表示形式 |
|---|---|---|
| `yoy_index` | 前年同月 = `100` の指数（例: `103.2`） | 小数第 1 位までの指数（`103.2`）をそのまま出し、`%` は付けない |
| `yoy_pct` | 前年同月比の増減率（例: `+3.2%` は `3.2`） | `100 + v` の指数（`103.2`）に換算して出し、開示元ごとの表記差を吸収する |
| `rate` | 前年比ではない比率（粗利率・稼働率・解約率・EC 化率など） | 数値の末尾に `%` を付けて出す（例: `51.6%`） |
| `number` | 実数（売上高・客数・店舗数・件数など） | 整数は 3 桁カンマ区切り、小数は末尾の不要な `0` を除いて出す |

行名からの系列分類（`monthly_series_kind`）、TOP の代表値選択、新着判定、業種分類の規則は以下のとおりである。

| 分類・属性 | 判定規則 |
|---|---|
| `all_store`（全店前年比） | 行名に `全店` または `全社` を含み `既存` を含まない行、またはスコープ無しの `売上高`・`連結売上高`・`客数`・`客単価` 行のうち、内訳（`breakdown`）が無く、`会員数` を含まず（#366）、指標種別が `other`・`count`（売上総利益・売上個数等）ではなく、`unit` が `yoy_index` または `yoy_pct` の行とする |
| `existing_store`（既存店前年比） | 行名に `既存` を含み、内訳が無く、`会員数` を含まず、指標種別が `other`・`count` ではなく、`unit` が `yoy_index` または `yoy_pct` の行とする |
| `store_count`（店舗数） | 行名に `店舗数` を含み、フロー・調整語（`出店`・`退店`・`純増`・`新設`・`改装`・`業態転換` 等）を含まず、`unit` が `number` の行とする |
| TOP の代表前年比セル | `all_store`・`existing_store` それぞれについて、グループ・セグメント・国・チャネル・内訳がすべて空で指標が `売上高` または `連結売上高` の会社全体行（優先段 0）を最優先し、会社全体行が無い会社でのみ客数・客単価やセグメント付き行（優先段 1）を使う。同一優先段内では値がある最大の `(year, month)`、同月なら `sort_order` 昇順・`element` 昇順で 1 行を選ぶ |
| `ingested_today` と `is_new` | `monthly_tables.updated_at` が JST 当日 0:00 以降なら `ingested_today: true`（`NEW` バッジ対象）、JST 前日 0:00 以降なら `is_new: true`（`新着` チップ対象。夜間更新分を翌日いっぱい拾えるようにする）とする |
| `industry`（月次業種） | 東証 33 業種（多くが `小売業` に集まる）とは別に、`monthly_issuers.industry` で外食・アパレル・ドラッグストア等を管理する。空文字または未設定は `未分類` とする |

## TOP

### 目的

月次データを収録している発行体を新着・業種・社名検索で絞り込み、最新月の全店・既存店前年比を見比べて目的の会社を開く。

### 要素

`#monthly-top` 上部の `.row` に検索入力 `#monthly-sym`（`placeholder="銘柄名 or コード"`）と候補リスト `#monthly-suggest`（`.suggest`）を置き、その下にチップ列 `#monthly-groups`、本体に `#monthly-list` 内のテーブル `#monthly-tbl`（`table.sheet`）を置く。

チップ列 `#monthly-groups` の構成と初期選択は以下のとおりである。

| 面 | チップの並び順 | 初期選択チップ |
|---|---|---|
| 公開面（`/monthly`） | `すべて`（`__all__`）→ `新着`（`__new__`）→ 1 社以上属する `industry`（日本語ロケール順） | `すべて` を選ぶ |
| 個人ツール（`/app`） | `新着`（`__new__`）→ 1 社以上属する `industry`（日本語ロケール順） | `is_new: true` の会社が 1 社以上あれば `新着` を選び、0 社のときは先頭の `industry` チップを選ぶ |

`#monthly-tbl` の列は次のとおりである。公開面は会社名・月次業種・前年比 2 列・公表日。個人ツール（`/app`）は会社名の右に市場と東証 33 業種を足す。行の順は `GET /api/v1/tables` の順（コード昇順）で、列見出しでは並べ替えない。

| 列名 | 表示内容 |
|---|---|
| `会社名` | 4 桁コード + 半角スペース + 社名の先頭 5 文字（例: `9983 ファースト`）を 1 行で出し、`ingested_today: true` の会社には右に `NEW` バッジ（`span.badge.new`）を添える |
| `市場`（`/app` のみ） | `fmtMarket` |
| `業種`（`/app` のみ） | 東証 33 業種を `fmtSector` で出す |
| `月次業種` | `monthly_issuers.industry`（未設定は `その他`）を出す |
| `全店(前年比)` | 全店代表行の最新値を指数（例: `103.2`）で出す。該当系列が無い会社は `-` を出す |
| `既存店(前年比)` | 既存店代表行の最新値を指数で出す。該当系列が無い会社は `-` を出す |
| `公表日` | その銘柄の、`confidence` が `exact` または `estimated` で `published_on` がある行のうち、対象月 `(year, month)` がいちばん新しい行の公表日を `YYYY-MM-DD` で出す。`estimated` は末尾に `頃` を付け、セルは `td.pub-est`（`color: var(--sub)`）。`title` に対象の `{year}年{month}月` を入れる。`unknown` だけ、または日付が無い銘柄は空欄 |

### 操作

`#monthly-groups` のチップを押すと、確定済み検索語をクリアして対象の発行体だけで表を即座に描き直す。

`#monthly-sym` への入力中は `#monthly-tbl` を書き換えず、読み込み済みの月次発行体リストから一致する最大 20 件を `{4桁コード} {正式社名}` で `#monthly-suggest` に出す（`/api/stocks/search` は呼ばない）。`Enter` キーまたは `#monthly-suggest` の候補クリックで検索語を確定し、選択中のチップに関わらず全発行体を対象に社名・コード（4 桁・5 桁）・`industry`・`sector33` の部分一致で `#monthly-tbl` を絞り込む。`#monthly-sym` を空にして `Enter` を押すかチップを押すとチップ絞り込みへ戻り、`Escape` キーで `#monthly-suggest` を閉じる。

`会社名` セル（`td.name`）を押すと Detail へ遷移する。公開面の行内リンク `<a href="/monthly/{code4}?from=monthly">` は通常クリック時に `history.pushState` で画面遷移し、`Ctrl` キーや `Cmd` キーを押しながらのクリックでは別タブで開く。

### 空とエラー

TOP における欠損セル・0 件・エラー時の表示は以下のとおりである。

| 状態 | 表示先と文言 |
|---|---|
| `全店(前年比)` または `既存店(前年比)` に該当系列が無い | 該当セルに `-` を出す |
| `公表日` に出せる日付が無い（`unknown` のみ、または行が無い） | 該当セルは空欄 |
| 登録発行体が 0 件、選択チップの対象が 0 件、または `GET /api/v1/tables` が失敗 | 表を出さず、`#monthly-list` に `登録された月次データはありません` を出す |
| 確定した検索語に一致する発行体が 0 件 | 表を出さず、`#monthly-list` に `該当する発行体はありません` を出す |
| 公開面で未登録コードの `/monthly/{code4}` を直接リクエスト（`404`） | TOP 枠内に `発行体が見つかりません。` を出す |

### スマホと PC

`#monthly-tbl` は内容幅で置き、スマホ（`640px` 以下）では枠内を横スクロールする。

## Detail

### 目的

1 社の月次データについて、複数年の 1〜12 月比較グラフと、収録期間を時系列かつ指標・事業階層で整理した横スクロール年表を確認する。

### 要素

`#monthly-detail` 上部の `.phead` に戻るボタン `#monthly-back`（`戻る`）と社名見出し `#monthly-title`（`{正式社名} ({4桁コード})`）を置く。

その下に系列選択 `<select id="monthly-series">`、グラフ枠 `#monthly-chart`（年別の凡例 `.monthly-legend`、折れ線 SVG、ツールチップ `.monthly-tip`）、および横スクロール表 `#monthly-table-wrap`（`table.sheet.monthly-tl`）を順に並べる。

系列選択と年比較グラフ `#monthly-chart` の仕様は以下のとおりである。

| 要素 | 表示と選択規則 |
|---|---|
| `#monthly-series` | 値がある系列の選択肢を並べる。既定の選択は会社全体の `売上高` 前年比行 → `group` 付きを含む `売上高` 前年比行 → `series_kind == "all_store"` の行 → 先頭行の優先順で決める（国付きの行は会社全体扱いしない） |
| `#monthly-chart` | 横軸に `1月`〜`12月`（スロット幅 `28px` 未満では `1`〜`12`）を固定し、表示対象の各暦年を年ごとの色で折れ線描画する（最新年は濃い実線と値ラベル、過年度は `opacity: 0.4`）。前年比系列（`yoy_index`・`yoy_pct`）では `100` の基準破線を引く |
| `.monthly-tip` | グラフ上のホバーまたはタップ時に縦ガイド線とともに出し、対象月の各年の値を表示する |

横スクロール表 `table.sheet.monthly-tl` と年比較ポップアップ `#monthly-pop` の仕様は以下のとおりである。

| 項目 | 表示・整列規則 |
|---|---|
| 時間軸の列構成 | 左端に項目列（`.tl-corner`・`td.tl-name`）を固定し、その右に値が存在する最初の月から最新月までを古い月→新しい月の順で 1 行ヘッダー（`<span class="tl-hy">{YYYY}年</span>{M}月`）で横に並べる。年ラベル `{YYYY}年` は年境界（先頭列と各年 1 月）と最新月の列にだけ出し、他の列の `.tl-hy` は空にする（先頭列のすぐ右が 1 月なら先頭列には出さず、最新月が 1・2 月なら最新月にも出さない）。年ラベルは折り返さず、年境界では左寄せで右の列へ、最新月では右寄せ（`.tl-hy-end`）で左の列へはみ出してよい。先頭列と各年 1 月の左に縦罫線 `.tl-yb` を引く。初回描画時は最新月が見える右端へ横スクロール位置を合わせ（#434）、ツリーの開閉時は現在の横スクロール位置を維持する |
| 階層木と行表示 | 手書き木（`ISSUER_TREES`、`app/monthly/tree.py`）または行名構造からの自動木（`build_auto_tree`）により、上位指標（全店・既存店の売上高・客数・客単価、実数、店舗数等）とその配下の事業・業態・地域・内訳を 1 つの表で深さ優先順に並べる。子を持つ行には開閉トグル `.tl-tw`（展開 `▾`・折りたたみ `▸`）を置き、見出し節と未分類の `その他の項目` は `tr.tl-sec` の帯行にする |
| 前年比ヒート色 | 前年比の数値には `100` からの乖離に応じた背景色を塗る。`100` 超は赤 `rgba(211, 47, 47, α)`、`100` 未満は緑 `rgba(27, 138, 90, α)`、`100` ちょうどは無色とする |
| 行ホバー | データ行 `tr[data-series]` にポインタを乗せると、項目列から右端の月列まで行全体を `--row-sel` で塗り、上下に `#9aa5b1` の 1px 線を引く。前年比ヒート色のセルはヒート色のまま上下の線だけで行を追えるようにする。選択中の行（`.on`）は青い 2px 線を優先する |
| 年比較ポップアップ `#monthly-pop` | 月セル `td.num[data-m]` を押すと、その行の同じ月について `2024` 年以降（`MONTHLY_POPUP_MIN_YEAR = 2024`）の各暦年の値（実数と前年比が対になる行は `金額`・`前年比` の 2 列）を縦に並べた `#monthly-pop` をセル付近に表示する |

### 操作

`#monthly-series` の選択変更、または表のデータ行 `tr[data-series]` のクリックで対象系列が切り替わり、グラフ `#monthly-chart` が更新される（折りたたまれている行を `#monthly-series` から選んだときは該当ノードを自動で展開する）。月セル `td.num[data-m]` を押すと年比較ポップアップ `#monthly-pop` が開く（`×` ボタン、ポップアップ外のクリック、`Escape` キー等で閉じる）。

`td.tl-name.tl-tog`（`.tl-tw`）を押すと子孫行の折りたたみ・展開を切り替える。

### 空とエラー

Detail における空データ・欠損値・エラー時の表示は以下のとおりである。

| 状態 | 表示先と文言 |
|---|---|
| 収録年が 0 件、またはデータが空 | `#monthly-chart` に `データなし`、`#monthly-table-wrap` に空案内を出す |
| 個別の月に値が無い | 横スクロール表 `table.monthly-tl` のセルは空欄（空文字）とし、`#monthly-pop` では `-`（読込中は `…`）を出す |

### スマホと PC

横スクロール表 `table.monthly-tl` の左端項目列は PC（幅 `18em`）・スマホ（`640px` 以下、幅 `12em`、字下げステップも `0.6em` に圧縮）で左固定したまま月列を横スクロールできる。グラフ `#monthly-chart` はコンテナ幅に追従して再描画し、スマホ（`640px` 以下）では高さを `230px`（PC は `250px`）、軸ラベル文字を `13px`（PC は `11px`）にする。

## API

月次エンドポイントの一覧と共通規約は [API 仕様](api.md)「月次データ（`/api/v1/tables`）」、JS と DB テーブルの対応図は [画面設計: 月次](gen/monthly.md) を参照する。

| エンドポイント | 用途とアクセス制御 |
|---|---|
| `GET /api/v1/tables` | TOP 用に全発行体の配列を返す。各要素は `{code, name, years, market, sector33, industry, last_ingested_at, is_new, ingested_today, all_store_yoy, existing_store_yoy, latest_publication}`。`latest_publication` は日付のある最新対象月の `{date, confidence, year, month}`、出せないときは `null`（`confidence` は `exact` か `estimated`） |
| `GET /api/v1/tables/{code}` | 発行体の収録暦年一覧 `{code, years: [2024, 2025, …]}` を昇順で返す（4 桁・5 桁コード対応、未登録は `404`） |
| `GET /api/v1/tables/{code}/{year}` | 1 社 1 暦年の `{code, year, elements, tree, tree_metrics}`（自動木の場合は `tree_auto` と `tree_metric_parent` を含む）を返す。各要素は `label`（`display`・`metric`・`scope`・`group`・`segment`・`country`・`channel`・`breakdown`・`series_kind` 等）と `values`（`"1"`〜`"12"` の辞書）を持つ |
| `GET /api/v1/tables/{code}/{year}/doc` | 保存済みの開示テキストメモ `{code, year, text}` を返す（画面 JS からは呼ばず運用・MCP 用） |
| 書込系 `/api/v1/tables/…`（`POST`・`PUT`・`DELETE`） | 取込 `POST /ingest`、業種設定 `PUT /industry`、要素・値・メモの更新 API はすべてループバック接続専用（`forbid_proxied_monthly_write`）であり、リバースプロキシ経由（`X-Forwarded-For` 等あり）では `403` を返す |

## 対象外

以下の項目は本画面の対象外とする。

1. ブラウザ画面からの月次データの追加・編集・削除・業種変更は行わない（更新はすべてバッチまたはローカル・MCP 経由で行う）。
2. 複数の発行体を 1 枚のグラフに重ねて比較する機能は置かない。
3. 会計年度順（期首月始まり）の列並びは扱わず、すべて公表対象の暦年・暦月（`1`〜`12`）に統一する。
