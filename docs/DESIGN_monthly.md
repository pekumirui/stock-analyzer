# 月次タブ

参照。見た目と操作の正本。取込と unit は `DESIGN.md`。実装の約束は `AGENTS.md`。書き方は `docs/SCREEN_SPEC.md`。

## 誰のための画面か

月次売上を業種グループで眺め、気になった発行体の年次表まで降りる人。

## 画面と遷移

月次タブは TOP から始まる。TOP はグループチップと発行体表。チップをクリックすると表を絞り込む。会社名をクリックすると Detail へ。Detail は戻る操作、系列切替つきの棒グラフ、その発行体の暦年表。戻ると TOP に戻り、直前のチップ選択を保つ。年のドロップダウンは無い。Detail に左の発行体一覧は置かない。

## データ形

`monthly_issuers` が発行体ごとの月次属性を持つ。`stocks.sector33` とは別物。

| 列 | 型 | 意味 |
|---|---|---|
| `code` | TEXT PK | `stocks.code` と同じ 5 桁。FK は付けない |
| `industry` | TEXT NOT NULL | 月次業種。既定は `その他` |
| `last_ingested_at` | datetime NULL | その code への ingest が成功するたびに更新 |

書き込みは先に `db.get(Stock, code)`。無ければ 4xx `NOT_IN_MASTER`。既存の `monthly_tables` / `monthly_elements` / `monthly_values` は変えない。

**ingest の列と暦年。** `months` は PDF 左→右。同じ月番号が2回（Genky 型 13 列の Jun…Jun など）でもよい。年は列ごとに右端 + `as_of` から左へ割り当て、`(code, year, element, month)` に残す。一意月の `values` は `{月: 値}` のまま。重複時は列順配列（または列番号キー）。詳細は `DESIGN.md`。

**新着。** 仮想グループ。`last_ingested_at` の JST 日付が今日を含む直近 7 日。業種グループと重複してよい。JST の日付が今日なら、行に NEW を付ける。

**系列の対応。** PDF の `element` 名を ID にはしない。一覧とグラフは次の規則で行を拾う。`sort_order` が先の行を使う。

| 系列 | 条件 |
|---|---|
| 全店 | 名前に `全店` または `全社` を含み `既存` を含まず、unit が `yoy_index` または `yoy_pct` |
| 既存店 | 名前に `既存` を含み、unit が `yoy_index` または `yoy_pct` |
| 店舗数 | 名前に `店舗数` を含み、unit が `number` |

最新セルは値のある最大の `(year, month)`。無いときは空。表示の 100=フラットは既存の `fmtMonthlyCell` と同じ。`yoy_index` はそのまま。`yoy_pct` は `100+v`。その年に値が1つも無い行は年表に出さない（年ごとの表は union 行でも空なら描かない）。系列セレクトは年をまたいだ行を残す。

**行名。** yoy の保存名は常に `canonicalize_element_label`（末尾 `(前年比)`）。`init_db` / migrate は既存の短い yoy 名を正規名へリネームする（同一年の重複がなくても。例: `全店 売上高前期比` → `全店 売上高前期比(前年比)`）。正規名が既にあれば正規名を残し、値は非NULL優先。number（`店舗数` や number の `売上高`）は前年比を付けない。銘柄固有の旧名寄せは `app/issuer_aliases.json`（ingest は `as_of < until`、それ以外は `year <= until.year`。例: 141A0 は 2025-08-01 未満の旧名をトライアル付きへ。旧 PDF 名の再 ingest でも寄せ続けたい場合は `until` を遠く（例: 138A0 / KPI rename の `2099-12-31`）にする。rename のみ・DELETE は載せない）。SPA の年表・系列・チャートの行キーは `fmtMonthlyElement`（表示名）。年ごとの保存名が違っても表示名が同じなら1行。取り残した短い名も畳む。その年の値は、その年の保存 element のうち表示名が一致するものから取る。

AI による業種付けはしない。`industry` の更新は MCP と `PUT /api/v1/tables/{code}/industry`。SPA からは書かない。

## TOP

### 目的

グループを選び、その発行体の最新前年比を横並びで見る。

### 要素

`#monthly-groups` がチップ行。先頭は常に 新着。その後ろに、発行体が 1 社以上いる `industry` を日本語ロケールで並べる。件数 0 のチップは出さない。

`#monthly-tbl` の列は左からこの順。独立したコード列は出さない。行には `data-code` を付ける。セルは縦横罫線。表は列の中身の幅（空列で画面を埋めない）。

| 列 | 出所 |
|---|---|
| 会社名 | code + 半角スペース + 会社名の先頭 5 文字。今日 ingest なら NEW。このセルだけ Detail へ |
| 市場 | プライムは 東証P、スタンダードは 東証S、グロースは 東証G。先頭に色付き記号 |
| 業種 | `stocks.sector33`。末尾の「業」を外し先頭 5 文字 |
| 月次業種 | `monthly_issuers.industry` |
| 全店(前年比) | 系列マップの最新セル |
| 既存店(前年比) | 系列マップの最新セル |

### 操作

チップをクリックすると、そのグループの行だけ残す。新着は `is_new` が真の行。業種チップは `industry` が一致する行。会社名をクリックすると Detail を開く。チップ以外の列は遷移しない。

### 空とエラー

月次表が 1 件も無いときは「登録された月次データはありません」。系列が無いセルは空白。一覧 API が失敗したらその文を出す。表は出さない。

### スマホと PC

同じ構造。チップは折り返す。表は横スクロール。縦横罫線。幅 1100px で二段組にしない。

## Detail

### 目的

1 発行体の系列を月次で比べ、PDF の全項目を年ごとに読む。

### 要素

`#monthly-back` が TOP へ戻る。見出しは会社名と code。

`#monthly-series` は単一の `<select>`。option は年表に出る表示名と同じ名前・同じ順（年をまたいで重複は除く。キーは `fmtMonthlyElement`）。チャートは選んだ行をそのまま描く。既定は 全店売上高(前年比) に当たる行があればそれ、無ければ先頭行。系列名はここに出す。チャート内には題名を描かない。

`#monthly-chart` は年ごとのクラスタ棒グラフ。積み上げではない。X は 1月〜12月。系列は、選んだ行に値が 1 つでもある暦年のうち、最新暦年とその前2年（例: データが 2026 までなら 2026 / 2025 / 2024。より古い年は出さない）。年表と同じ3年。色は暦年で固定し、表示順では付け替えない。`MONTHLY_YEAR_COLORS`（#0077b6 / #2e8b57 / #b8860b / #8e4ec6）を `year % 4` で引く。凡例も同じ色。2025 は窓がずれても同じ色。既定の指標は 全店売上高(前年比) に当たる行。前年比グラフは 100 に水平線を引く。100 未満でも棒は年の色のみ（赤の半透明重ねは付けない）。店舗数や実数の行に 100 線は無い。ライブラリは足さない。`static/index.html` 内の SVG または canvas。系列名の題は描かない。Y軸に目盛の数字を描く。左ガターに軸、下に月ラベルと年凡例。互いに重ねない。スマホでは viewBox を画面幅に合わせ、月・凡例・Y軸を他サイトの月次売上グラフと同じくらい読める大きさにする。

グラフと表を同じカードに入れない。

`#monthly-table-wrap` は暦年ごとの表を新しい年が上になるよう重ねる。出すのは最新暦年とその前2年（データがある年。例: 2026 までなら 2026 / 2025 / 2024）。より古い年は出さない。チャートと同じ3年。overflow-x は auto。各表の左上セルは暦年。赤地・白文字・太字。1〜12月の見出しは薄いグレー（#eceff2）、太字、中央揃え。行は表示する年の表示名（`fmtMonthlyElement`）の和集合で、どの年表も同じ順。保存名が年ごとに違っても表示名が同じなら1行。その年の値は、その年の保存 element のうち表示名が一致するものから取る。その年に無い行は空セル。保存名は PDF のまま（全社を全店に書き換えない）。並べるときだけ 全社・全店舗 を 全店 と同じ枠とみなす。順は 全店 → 既存店 → FC店 → 名前付きセグメント（新しい年から見た初出）。FC が無い発行体はその枠を飛ばす。各塊の中は 売上高 → 客数（来客数含む）→ 客単価（単価）→ 店舗数 → その他。ブランド付きはセグメント（`カラオケ全店 売上高(前年比)` は カラオケ）。指標でセグメントを混ぜない。項目列は太字。セルは縦横罫線。ゼブラは付けない。選択中の系列行だけ `--row-sel`。1〜12月列は表示値の最長に揃えた同一幅（`--monthly-m-w`）。空セルと項目列は幅の根拠にしない。項目列は min-width で潰れない。PC の左端 th/td は sticky、不透明な白（暦年セルは赤）、z-index。月の数字がラベルの下や上に出ない。右端の月列は sticky にしない。スマホでは左端 sticky を外し、項目列を短くして月列が見えるようにする。横スワイプで月列が普通に動く。

### 操作

`#monthly-back` で TOP に戻る。直前のチップを保つ。グラフの指標は `#monthly-series` の切替、または年表の該当行をクリックして変える。年の選択 UI は置かない。

### 空とエラー

years が空なら「データなし」。選んだ系列に値が無い年はグラフから落とす。年表は残す。セレクトは常に年表の行名。チャート用の 3 行が PDF に無くても、年表は全行のまま。

### スマホと PC

TOP と同じ。年表は横スクロール。項目列は min-width で潰れない。PC は左端 sticky。スマホは `@media (max-width:640px)` で左端 sticky を外し、項目列を短くする。右端の月列はピン留めしない。チャートの Y軸数字・月・凡例はスマホでも読める大きさ。系列名は `#monthly-series`。二段組にしない。

## API

`GET /api/v1/tables` は `{code, name, years}` を維持し、次を足す。`market`, `sector33`, `industry`, `last_ingested_at`, `is_new`, `ingested_today`, `all_store_yoy`, `existing_store_yoy`。

`GET /api/v1/tables/{code}` と `GET /api/v1/tables/{code}/{year}` の形は変えない。Detail の年表は今どおり years を並列 GET する。

`PUT /api/v1/tables/{code}/industry` の body は `{industry}`。stocks に無い code、月次表が無い code は 4xx。

ingest は `monthly_issuers` を upsert し `last_ingested_at` を今にする。industry は既にあれば触らない。無ければ `その他`。

エラー包みは既存どおり `{"error": {"code": "...", "message": "..."}}`。

## 対象外

AI による月次業種の自動分類。業種マスタの固定リスト。SPA からの industry 編集。型の調査タブ。PDF 取込そのものの置き換え。新しいフロントライブラリ。
