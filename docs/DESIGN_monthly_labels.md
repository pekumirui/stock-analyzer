# 月次の行名

正本。保存名は `canonicalize_element_label`（書き込み時）。GET の表示名と層は `monthly_element_label`。実装は `app/monthly_ingest.py`。
year GET の各行は保存 `element` に加え、派生の `label`（display / group / metric_kind / series_kind / 7層 / breakdown_depth）を返す。SPA は再パースしない。
銘柄固有の残りは `config/issuer_aliases.json`。画面の並びは `docs/DESIGN_monthly.md`。
取込と unit は `DESIGN.md`。

新しい例外は **このファイルに箇条書きで足す**。`AGENTS.md` / `DESIGN.md` / `DESIGN_monthly.md` の1行に追記しない。

## 層

空白区切り `[国] [セグメント] [時間軸] [チャネル] [スコープ] [指標] [内訳]`。無い層は出さない。`label` は空層も `""` で返す。

| 層 | 値 | 変換 |
|---|---|---|
| 国 | `日本` / `海外` | 裸の `国内` だけ `日本`。`国内リテール` など複合はセグメント。`中国` もセグメント |
| 時間軸 | `単月` | canonicalize 後はほぼ空。`label.time_axis` として出す |
| チャネル | `直営` / `FC` / `直営+FC` | 直営を全店先頭に上げない（`焼肉 直営 店舗数`） |
| スコープ | `既存` / `全店` / `全社` | `既存店`/`全店舗` は短く。`全社` は `全店` に畳まない（アルペンの全社計≠全店計）。`全店舗数` は `店舗数` |
| 指標 | `売上高` / `連結売上高` / `客数` / `客単価` / `購入お客様数` / `出店` / `退店` / `店舗数` / `稼働店舗数` / `取扱高` / `稼働日修正後` | 開店/新規/開設 → 出店。閉店/閉鎖/撤退 → 退店。転換出店は出店に畳まない。`連結` は指標の接頭辞（`連結売上高`）。セグメントにしない。`取扱高` は全店を補わない。`稼働日修正後` も全店を補わない。`購入お客様数` も全店を補わない（客数に畳まない）。`客単価` も全店を補わない。`稼働` + `店舗数` → `稼働店舗数`（セグメントに `稼働` を残さない） |
| 内訳 | `ドラッグ` / `調剤` / `物販`、領域の子、`稼働店舗数` の子 | 売上高の子、または指標が `稼働店舗数` のとき。`内)` / `（内` / `うち` と末尾 `店舗` を剥がす。`調剤事業` や `内アパレル` はセグメント。leftover が グロース領域/サステナブル領域 + 子なら内訳へ。`稼働店舗数` の子は `管理テナント数` / `取引店舗数` / `増加` / `減少`（depth 1）。保存は1語。`label.breakdown_depth` は 0=親 / 1=内訳 / 2=小枝。`_BREAKDOWN_CANON` には足さない |

## 補う・落とす

- スコープが空で指標が 売上高/客数 なら `全店` を補う。`客単価` は補わない
- `取扱高` は指標。全店は補わない。`CPAソリューション事業 取扱高` の leftover は `CPAソリューション事業`
- `稼働日修正後` は指標。全店は補わない。`ASKUL事業 稼働日修正後` の leftover は `ASKUL事業`
- `購入お客様数` は指標。全店は補わない。客数に畳まない。`ASKUL事業 購入お客様数` の leftover は `ASKUL事業`
- 修飾の `購入お客様` は落とす（`ASKUL事業 購入お客様 客単価` → `ASKUL事業 客単価`）
- 店舗数・出店/退店にはスコープを補わない。出店/退店に 全店/既存 は付けない（スコープ層は 売上高/客数）
- 出店/退店は指標（店舗数にしない、セグメントにもしない）
- 並び位置: 出店 → 退店 → 純増/新設/改装/業態転換 → 店舗数。純増等は名前を変えないが指標位置へ
- 実店舗/EC はセグメント。`実店舗数` → `実店舗 店舗数`。店舗数 unglue で `実` に割らない
- `稼働店舗数` は指標。`稼働 店舗数` / `稼働店舗数` → `稼働店舗数`。子の `管理テナント数` / `取引店舗数` / `増加` / `減少` は内訳（売上高のドラッグ系と同じ depth 1）
- 落とす: 合計/総計/小計/計、店舗数の 月末/期末、対（対前年比の残り）、累計、店舗状況（表見出し）、拠点数（表見出し）、購入お客様（客単価の修飾）、`（％）`/`（%）`/`(％)`/`(%)`/`%`（単位ノイズ）、`（百万円）`/`(百万円)`、`売上（％）`/`売上（%）`、`※`（注記記号）、`(1)` / `（2）` / `①` / `②` など数字だけの括弧・丸数字注番号、`2026年度` / `2026年（令和8年）度` などの年度帯、`昨対` / `昨対増減率` / `昨年比` / `昨年比増減率`（前年比見出し。セグメントにしない）、`内数`（`うち` と同じ内訳見出し。チャネルの FC は残す）
- `総店舗数` / `全店舗数` → `店舗数`
- `客 数` / `売 上` の分割トークンは `客数` / `売上` に繋ぐ
- `単月` / `Monthly` は指標がある行、または yoy でスコープ行（セグメント付き含む）では落とす。累計列は HTML パーサが落とす
- yoy でスコープだけ（`全店` / `既存` / `全社`）、または `ゼビオ 単月 既存` のようにセグメント+スコープなら `売上高` を補う。例外: チャネル付きの `直営 全店(前年比)` は触らない
- アルペン例: `既存店計 単月` / `全店計 単月` / `全社計 ※ 単月` → 各スコープの `売上高(前年比)`
- ゼビオ例: `ゼビオ 単月 既存店` / `ゼビオ 単月 全店` → `ゼビオ 既存 売上高(前年比)` / `ゼビオ 全店 売上高(前年比)`
- `開設` / `開設数` → `出店`。`撤退` / `撤退数` → `退店`。`転換出店` は `出店` に畳まない
- 売上高の leftover が `ドラッグ` / `調剤` / `物販`（または `内)ドラッグ店舗` / `（内 調剤）`）なら内訳へ移す。`MKG ドラッグ 全店 売上高` → `MKG 全店 売上高 ドラッグ`。出店の `（内 開店）` は内訳にしない
- 売上高の leftover が グロース領域/サステナブル領域 + 子なら内訳へ。中節はプロパティ, 専門通販, 呉服関連, アパレル雑貨, その他。小枝はプロパティ下の ホテル / インカム太陽光、専門通販下の 化粧品健康食品 / グルメ / ワイン / ナース関連。`インカム、太陽光` は1行の `インカム太陽光`。`アパレル・雑貨` は `アパレル雑貨`。親が無い ホテル/その他はセグメントのまま。`_BREAKDOWN_CANON` には足さない
- `連結` はセグメントにしない。`連結売上高` / `連結 売上高` / `連結 全店 売上高` → `全店 連結売上高`。yoy の `連結 全店` は `全店 連結売上高(前年比)`。`連結営業利益` や `連結 営業収益` のように連結で始まる指標名も leftover に残さない

## yoy / number

- yoy（`yoy_index` / `yoy_pct`）は `前年同月比` / `前年比` / `前年同月` / `(前年比)` / `（前年比）` を安定するまで除き、末尾に `(前年比)` を1回
- number には前年比を付けない。number の `売上高` と yoy の `売上高(前年比)` は別行
- 保存も表示も同じ規則。保存名は常に正規名。NFKC はしない

## 同一行・migrate

- ingest / POST は正規化してから既存行を探す。正規化後に同じなら同一行
- 短い保存名（`売上高` / `カラオケ全店 売上高`）に正規名が当たれば値を UPSERT し、保存名を正規名へリネームする
- `init_db` / migrate は number / yoy とも正規名へ（同一年の重複がなくても。例: `全店 売上高前期比` → `全店 売上高(前年比)`）
- 正規名が既にあれば正規名を残し、値は非NULL優先で短い行を消す。同じ月が両方非NULLで不一致なら正規名を残して記録する
- GET は保存名のまま。派生の `label` だけを足す。DB は書き換えない
- SPA の年表・系列・チャートの行キーは `label.display`。年ごとの保存名が違っても表示名が同じなら1行。取り残した短い名も畳む。その年の値は、その年の保存 element のうち表示名が一致するものから取る
