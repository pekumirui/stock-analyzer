# 月次の行名

正本。保存名も表示名も `canonicalize_element_label`。実装は `app/monthly_ingest.py`。
銘柄固有の残りは `app/issuer_aliases.json`。画面の並びは `docs/DESIGN_monthly.md`。
取込と unit は `DESIGN.md`。

新しい例外は **このファイルに箇条書きで足す**。`AGENTS.md` / `DESIGN.md` / `DESIGN_monthly.md` の1行に追記しない。

## 層

空白区切り `[国] [セグメント] [チャネル] [スコープ] [指標]`。無い層は出さない。

| 層 | 値 | 変換 |
|---|---|---|
| 国 | `日本` / `海外` | 裸の `国内` だけ `日本`。`国内リテール` など複合はセグメント。`中国` もセグメント |
| チャネル | `直営` / `FC` / `直営+FC` | 直営を全店先頭に上げない（`焼肉 直営 店舗数`） |
| スコープ | `既存` / `全店` | `既存店`/`全店舗` は短く。`全社` は `全店`。`全店舗数` は `店舗数` |
| 指標 | `売上高` / `客数` / `客単価` / `出店` / `退店` / `店舗数` | 開店/新規 → 出店。閉店/閉鎖 → 退店 |

## 補う・落とす

- スコープが空で指標が 売上高/客数/客単価 なら `全店` を補う
- 店舗数・出店/退店にはスコープを補わない。出店/退店に 全店/既存 は付けない（スコープ層は 売上高/客数/客単価）
- 出店/退店は指標（店舗数にしない、セグメントにもしない）
- 並び位置: 出店 → 退店 → 純増/新設/改装/業態転換 → 店舗数。純増等は名前を変えないが指標位置へ
- 実店舗/EC はセグメント。`実店舗数` → `実店舗 店舗数`。店舗数 unglue で `実` に割らない
- 落とす: 合計/総計/小計/計、店舗数の 月末/期末、対（対前年比の残り）、累計、店舗状況（表見出し）、`（％）`/`（%）`/`%`（単位ノイズ）
- `客 数` / `売 上` の分割トークンは `客数` / `売上` に繋ぐ
- `単月` / `Monthly` は指標（売上高/客数/客単価など）がある行だけ落とす。`単月売上` → `売上高`。空指標の `単月 既存(前年比)` は残す（ゼビオなど月次/累計の別系列）
- yoy でスコープだけ（`全店` / `既存`）なら `売上高` を補う。例外: チャネル付きの `直営 全店(前年比)` は触らない

## yoy / number

- yoy（`yoy_index` / `yoy_pct`）は `前年同月比` / `前年比` / `前年同月` / `(前年比)` / `（前年比）` を安定するまで除き、末尾に `(前年比)` を1回
- number には前年比を付けない。number の `売上高` と yoy の `売上高(前年比)` は別行
- 保存も表示も同じ規則。保存名は常に正規名。NFKC はしない

## 同一行・migrate

- ingest / POST は正規化してから既存行を探す。正規化後に同じなら同一行
- 短い保存名（`売上高` / `カラオケ全店 売上高`）に正規名が当たれば値を UPSERT し、保存名を正規名へリネームする
- `init_db` / migrate は number / yoy とも正規名へ（同一年の重複がなくても。例: `全店 売上高前期比` → `全店 売上高(前年比)`）
- 正規名が既にあれば正規名を残し、値は非NULL優先で短い行を消す。同じ月が両方非NULLで不一致なら正規名を残して記録する
- GET は保存名のまま
- SPA の年表・系列・チャートの行キーは `fmtMonthlyElement`（同じ規則）。年ごとの保存名が違っても表示名が同じなら1行。取り残した短い名も畳む。その年の値は、その年の保存 element のうち表示名が一致するものから取る

## 銘柄固有

`app/issuer_aliases.json`。キーも canonicalize してから載せる。マップに無い名前はそのまま。

- ingest は `as_of < until`
- POST / PUT / 新規行 / migrate は `year <= until.year`
- rename のみ。DELETE は載せない
- 旧 PDF 名の再 ingest でも寄せ続けたい場合は `until` を遠くする（例: 138A0 / KPI の `2099-12-31`）
- 例: 141A0 は 2025-08-01 未満の旧名をトライアル付きへ
- `scripts/test_monthly_ingest.py` に銘柄分岐は足さない。テストは `plan_issuer_alias_cases` が JSON から生成する

## 拒否

- 前期・前年同月・前年同期の実数行（直後が `比` でない）は canonicalize 前に 400 `PRIOR_PERIOD_ELEMENT`。ingest / POST elements のみ
- 正規化後 50 文字超は 400
