# PTS タブ

取得と保存は `DESIGN.md`「PTS ランキング」。共通見た目は `docs/SCREEN_SPEC.md`。

## 誰のための画面か

夜間 PTS で大きく動いた銘柄を見て、翌朝の東証の寄り付きが PTS の値にどれだけ付いていったかを確かめる自分。

## 画面と遷移

ランキング 1 画面。ヘッダーの `PTS` タブ（`data-tab="pts"`、ルートは `#pts`）。銘柄名をクリックするとチャートタブ。

## データ形

`GET /api/pts` の 1 回分。行はランキングの順位順。翌営業日の始値は日次バッチ（19:30）の後に埋まり、それまでは null。

## ランキング

**目的。** あるセッション・ある取得時刻の PTS ランキングと、翌始値とのギャップを一覧で見る。

**要素。** 上から:

1. 操作の行。セッション日 `#pts-date`（新しい順、最大 60 日）、ランキング `#pts-ranking`（値上がり / 値下がり / 出来高）、取得時刻 `#pts-at`（`MM-DD HH:MM（株探の HH:MM現在）`、新しい順）、`#pts-info`（`セッション日 終値比 / 翌営業日 日付`。翌始値が 1 件も無ければ `未取込`）
2. `#pts-summary`。翌始値のある銘柄数、PTS→翌始値 の平均、追随率の中央値。翌始値が 1 件も無ければ空
3. 表 `#pts-tbl`。列は左から 順位、銘柄（名前 + 4 桁コード）、市場、終値（通常取引）、PTS（株価）、終値比（%）、PTS出来高、翌始値、終値→翌始値（%）、PTS→翌始値（%）、追随率

追随率は `(翌始値 − 終値) / (PTS − 終値)`。1 は PTS どおりに寄った、0 は終値に戻った。PTS と終値が同じなら `–`。翌営業日が表の多数と違う銘柄（売買停止明けなど）は翌始値の横に `M/D` を小さく出す。% は正が赤、負が緑。

**操作。** セッション日・ランキングを変えると、その組の最新の取得を出す。取得時刻を選ぶとその回を出す。銘柄名でチャートタブへ。

**空とエラー。** データが 1 件も無ければ `PTS のデータがまだありません`。選んだ日にそのランキングが無ければ `この日のランキングはありません`。API 失敗は `読み込みに失敗しました` で表を空にする。

**スマホと PC。** 同じ構造。操作の行は折り返す。表は中身の幅で、足りなければ横スクロール。

## API

`GET /api/pts?date=YYYY-MM-DD&ranking=night_up&at=YYYY-MM-DD HH:MM:SS`

```json
{
  "dates": ["2026-10-16"], "date": "2026-10-16", "ranking": "night_up",
  "snapshots": [{"fetched_at": "2026-10-17 00:00:00", "as_of": "23:45"}],
  "fetched_at": "2026-10-17 00:00:00", "as_of": "23:45",
  "rows": [{"rank": 1, "code": "73600", "name": "オンデック", "market": "東Ｇ",
            "base_close": 711, "pts_price": 900, "pts_chg_pct": 26.58, "volume": 1700,
            "next_date": "2026-10-19", "next_open": 850,
            "open_gap_pct": 19.55, "open_vs_pts_pct": -5.56, "follow_ratio": 0.74}],
  "summary": {"n": 1, "avg_open_vs_pts_pct": -5.56, "median_follow_ratio": 0.74}
}
```

データが無ければ `rows: []`、`snapshots: []`、`summary: null`。

## 対象外

- 日中の PTS（デイタイムセッション）
- 複数セッションをまたいだ追随率の集計（`stock.db` を `analyzer/` で読む）
- 株探の市場別・時価総額別の絞り込み
