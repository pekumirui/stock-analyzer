## 結論

- **売上は月次でほぼ決まる。** 月次を持つ条件（B・C・E・F）は −4.5〜−4.8%。持たない A は −20.6%。説明資料だけの D は −15.7% で、A よりは上がるが月次には届かない
- **利益は月次で一段改善し、説明資料の上乗せは小さい。** 営業利益は A −47% / D −32% / 月次のみ B −19%・C −25% / 両方 E・F とも −18〜−19%。Claude では月次＋説明資料で −11〜13% まで寄ったが、Grok 4.6 の 1 回では説明資料を足しても営業利益はほとんど動かない
- **月次の PDF と API は売上の精度が同じ。** B −4.7% / C −4.5%。推定トークンは B 161k → C 76k（−53%）。F が E より多いのは、F が説明資料を多く読んだためで、API が高いわけではない
- 売上の残り −4.6% は月次では取れない。今回の決算は月次合計（7,325）の約 1.052 倍で、Grok も Claude と同じく過去の短信/月次倍率（約 1.00〜1.01）を使った
- A〜F は 1 回ずつなので、条件どうしの細かい差はぶれの範囲になりうる
