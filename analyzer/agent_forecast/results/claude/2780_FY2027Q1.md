# コメ兵ホールディングス 2027年3月期 1Q単独（2026-10-07 実行。E・F を Opus / Sonnet で 2 回ずつ）

設定は `targets/2780_FY2027Q1.json`。ベンダーは Claude（`claude -p`、Claude Code 2.1.288）。モデルは `--model opus`（claude-opus-5-5）と `--model sonnet`（claude-sonnet-5-5）。A〜D は回していない。全条件に渡した財務 JSON は [`2780_FY2027Q1_financials.json`](../2780_FY2027Q1_financials.json)。各回の実行ログ（文章・ツール呼び出し・トークン。読んだ中身と思考の本文は入っていない）は [`2780_FY2027Q1_logs/`](2780_FY2027Q1_logs/)。

## 結論

- **売上は月次でほぼ決まる。** 8 回とも誤差 ±0.6% 以内。ブランド・ファッション事業の 4〜6 月の月次合計 64,210 が決算のセグメント売上とほぼ同じ（前年 1Q は月次 44,725・セグメント 44,751）で、全員がこれにタイヤ・ホイール事業の約 1,400〜1,500 を足した。ＫｅｅＰｅｒ技研（月次の 1.05 倍に上振れ）と違い、月次と決算のずれがない
- **差が出たのは販管費。** Opus は 4 回とも説明資料 p.47 の通期の販管費計画（+9,900、+26%）を使い、1Q の販管費を 10,750〜11,150 と多めに置いた。営業利益の誤差は E −6.6 / +0.5、F −12.3 / −6.6。Sonnet は前期 4Q の 10,142 から少し足しただけで 10,500〜10,650 とし、営業利益の誤差は E +1.9 / −0.9、F −5.2 / −0.5
- **Sonnet の F は説明資料を 1 本も読んでいない。** 2 回とも README・financials.json・月次 MCP だけで、実質は条件 C。それでも営業利益は 4 組のうち 2 番目に当たった。今回の 1Q では説明資料が利益を当てる役に立っておらず、むしろ Opus の販管費を押し上げた
- **費用は Sonnet が Opus の 1/3〜1/5。** 1 回あたり Opus は E 0.87 / F 0.83 ドル、Sonnet は E 0.27 / F 0.17 ドル。総トークンも Sonnet は半分以下
- **月次は API の方が安い（ＫｅｅＰｅｒ技研と同じ傾向）。** 総トークンの平均は Opus で E 410k → F 337k（−18%）、Sonnet で E 170k → F 159k（−6%）。E の PDF は 1〜4 本しか読んでいない（6 月度の PDF に 4〜6 月がそろっている）ので、差は小さい
- 2 回ずつなので、E と F、Opus と Sonnet の営業利益の差（数 %）はぶれの範囲になりうる
- 根拠はどの回も作業フォルダの数字から組み立てられている。発表日 2026-08-13 は Opus 5.5 の知識の期限（2026 年 6 月）より後。Sonnet 5.5 の期限は確かめていない
