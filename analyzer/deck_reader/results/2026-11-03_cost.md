## 出力の中身

v2・effort low でも、出力 5.0 万トークンのうち JSON は半分ほど。残りは考えた分（p10 の貸借対照表は JSON 2,800 字に出力 6,900 トークン）。`claude -p` では考えるのを止められない（`MAX_THINKING_TOKENS=0` を試したが変わらない）。

入力の 22 万トークンは、ほとんどが `claude -p` の分（Claude Code の指示文・Read の往復。1 ページ約 1.4 万トークン）。資料の中身（画像・文字・プロンプト）は 1 ページ 3〜4 千トークンの見込み。
