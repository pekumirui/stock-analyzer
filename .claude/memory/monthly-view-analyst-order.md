月次 Detail の横持ちは、一番上の行を指標（既存 → 全店 → 店舗数の順）にして、開くとブランド・事業・店の木を出す形で確定した（2026-10、#436〜#438）。指標タブ（物語で 13 個）は「見にくい」と却下された。ブランドは一番上の指標の下に 1 回だけ出し、直営 / FC はブランドの行の子にする。名前は短くする（直営+FC を外す、子は親との差だけ）。

**Why:** ユーザーの分析の順番は、既存店売上高 → 客数・客単価 → 全店と店舗数 → どのブランドが効いているか。「既存店の伸びが重要」と明言している。スマホで見るので、同じブランドが 2 回出る、名前が 2 行に折り返す、といった形は嫌われる。

**How to apply:** 月次の画面を変えるときは、既存店売上高を先頭に置き、指標を決めてから組織へ降りる流れを崩さない。新しい形を試すときは、物語（3097）と大庄（9979）をスマホ幅で撮って見せる。関連: [[monthly-computed-metrics-later]]
