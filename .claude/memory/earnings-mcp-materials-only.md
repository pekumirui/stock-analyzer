エージェント向けの決算ツール（KAB-404、`mcp/earnings_tools.py`）は、決算速報と同じ数字・PTS・バリュエーション・地合い・短信と説明資料を渡すだけにする。好決算スコア、既定の並び、足切りはサーバー側に作らない。

**Why:** ユーザーの判断は「数字が伸びている」だけでは決まらず、バリュエーションや地合いを合わせて見る。フィルターのやり方はエージェントの思考に任せたい（2026-11-09 に合成スコア案を却下）。

**How to apply:** ツールを足すときは画面の操作程度（日付・業種・Q・PTS 順・ページング）に留め、判断の入る指標や順位は足さない。足りない材料（例: ランキング外の PTS）は取込を足す方向で考える。
