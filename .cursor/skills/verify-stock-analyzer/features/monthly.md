# 月次

The monthly tab lists ingested issuer monthly-sales tables with industry chips, then opens a Detail view (series select, year-panel chart, and one horizontal 横持ち table: metric ▸ section tree across the shown years). It is not a TDnet day calendar.

## Sub-features

- `monthly-list` fills `#monthly-groups` (新着 + industry chips) and TEMP `IR（一時）` / `__ir__` (private `/app` only; codes from `GET /static/ir_monthly_codes.json`) and `#monthly-tbl` from `GET /api/v1/tables` (list 全店/既存店 YoY prefer company-wide 売上高/連結売上高; #337).
- `monthly-issuer-search` types into `#monthly-sym` (placeholder `銘柄名 or コード`) and fills `#monthly-suggest` from the loaded list (`monthlyRows` / `uniqueMonthlyIssuers`). Typing does not change `#monthly-tbl`. Enter or a suggestion pick commits `monthlySearchApplied` and filters the table (name / code / `industry` / `sector33`). It does not open Detail and does not call `/api/stocks/search`.
- `monthly-detail` opens `#monthly-detail` for a row `data-code` via `GET /api/v1/tables/{code}` then parallel `GET /api/v1/tables/{code}/{year}` for the latest calendar year and up to two prior years.
- `monthly-series` switches `#monthly-series` (default via `pickDefaultMonthlySeries`: unsegmented 売上高 yoy where `isAllStoreSalesYoy` — scope 全店 / 全社 / empty, and no country / segment / breakdown; else any such 売上高 yoy; else any `label.series_kind === "all_store"`; else the first ordered row) and redraws `#monthly-chart`.
- `monthly-timeline` renders one `table.monthly-tl` in `#monthly-table-wrap`: one column per month from the first to the last month with data across the shown years. Each month `th` is `<span class="tl-hy">YYYY年</span>M月` (after an empty corner `th.tl-corner`). The first column and each January carry `.tl-yb`. On render the wrap scrolls to the right end (latest month).
- `monthly-tree` lays rows out as metric ▸ section tree from the year GET `tree` / `tree_metrics` (`monthlyTreeModel` / `monthlyTreeHtml`). `td.tl-name.tl-tog` rows toggle ▸/▾ (`toggleMonthlyTimelineSection`). On first render (`monthlyTreeSeedOpen`) the first top metric starts open, and so does every top metric that has no company row (only section rows; 30860 `▾入店客数`). Heading sections are `tr.tl-sec` bands. 内数 sections are `tr.tl-part`. Rows outside the tree go under `その他の項目` (`N行`). Picking a series in a closed branch opens its path (`monthlyTreeReveal`). A metric row that has a company row shows that row's name: the auto tree drops 日本+海外 (`monthlyTreeTopName`), a config tree drops `(前年比)` from the company leaf (60360 `全社 売上高`, 30860 `総額 連結売上高`). With no company row it shows the metric name. A config-tree metric with one row and nothing under it is a flat `節名 葉` row (`monthlyTreeOtherName`, 60360 `直営 既存 売上高`); the auto tree keeps the stored name.
- `monthly-value` pairs `X` and `X(前年比)` in the same section into one row (`monthlyPairYoyRows`). The cell always shows the amount with `(yoy)` under it in `.tl-sub` (yoy only when that month has no amount). There is no `#monthly-value-tabs`. YoY heat is drawn on the cell. The row `data-series` is the amount id; `data-alt` is the yoy id.
- `monthly-popup` opens `#monthly-pop` on a `table.monthly-tl td.num[data-m]` click. It lists that month for every year ≥ 2024 (`MONTHLY_POPUP_MIN_YEAR`), newest first, and fetches missing years.
- `monthly-back` returns to TOP via `#monthly-back` while keeping the selected chip and any committed search filter.
- `monthly-route` persists `#monthly` or `#monthly/{code}` in `location.hash` + `localStorage` `ui.route`; reload/`restoreRoute` reopens TOP or Detail.

## How to get to it (user POV)

- Click `nav button[data-tab="monthly"]`.
- Type a known issuer name, 4-digit / 5-digit code, or industry fragment into `#monthly-sym` and press Enter (or pick `#monthly-suggest`) to filter `#monthly-tbl`. Click a company-name cell to open Detail.
- Click an industry / 新着 / TEMP `IR（一時）` chip in `#monthly-groups`. The 新着 chip is always rendered; if no issuer has `is_new`, selection falls back to the first industry chip but 新着 stays visible. Industry chips appear only for industries present in the list. `IR（一時）` renders only when `monthlyPublic()` is false (Basic `/app`); public `/monthly` omits it. `__ir__` keeps rows whose `monthlyCode4(code)` is in `/static/ir_monthly_codes.json` (from `config/ir_monthly.json`); empty filter copy is 「IR対象はありません」. A chip click clears the search field and `monthlySearchApplied`.
- Click a company-name cell (`.name`) in `#monthly-tbl` to open Detail.
- Change `#monthly-series` or click a `tr[data-series]` in the table.
- Click a ▸/▾ name cell to open or close a metric or section.
- Click a month cell to open `#monthly-pop`. Close it with ×, Esc, or a click outside.
- Click `#monthly-back` to restore TOP + chip.
- Reload with `#monthly` or `#monthly/{code}` (or the same path in `ui.route`) to restore TOP or Detail.

## Gotchas

- Empty `/api/v1/tables` renders「登録された月次データはありません」— that is empty ingest, or a Cloud Agent build that skipped VPS monthly copy. Not a render bug.
- `#monthly-suggest` is filled only from the loaded monthly list. Do not call `/api/stocks/search` here. A stock without monthly data must not appear. Empty query or no hits hide the box; that is not the ingest-empty copy.
- Committed search (`monthlySearchApplied`) filters `#monthly-tbl` and ignores chips until a chip click or empty Enter clears it. Typing does not write it. Zero hits after Enter is 「該当する発行体はありません」, not the ingest-empty copy.
- Mobile/IME: `compositionend` must refresh suggestions even when no trailing `input` fires. Queries fold via NFKC + hiragana→katakana, so `にとり` and fullwidth `９８４３` hit the same rows as `ニトリ` / `9843`.
- Detail with no years shows「データなし」.
- Public `/monthly/{code}` server HTML still has per-year `table.fin.monthly` for crawlers, then `monthly.js` redraws `#monthly-table-wrap` as the same `table.monthly-tl` (#440). An HTTP-only proof of public Detail sees the server tables, not the timeline.
- Changing only `location.hash` on an open `/app` does not reroute. Reload after setting `#monthly/{code}`.
- Timeline heat: YoY above 100 is red, below 100 green. Strength caps at ±20. Cells with no number are not painted. Rows with no values in the shown years are dropped.
- NEW badge uses `ingested_today` (JST today); 新着 chip window is `MONTHLY_NEW_DAYS` (7) via `is_new`.
- Stored YoY is `yoy_index` (100=flat). YoY display is the stored number. Number cells with a known display unit round half-up (`fmtMonthlyCell` / server `format_monthly_cell`). Units sit on the row name via year-GET `label.display` (`monthly_display_label`, e.g. `受注高（百万円）`). Stored `element` stays unit-free; `label.display` may add units. Year-panel chart (`drawMonthlyChart`): one SVG per displayed year, yoy gets a dashed 100 line, bar colors cycle `MONTHLY_YEAR_COLORS[year % 4]`, and each bar shows a value label (`.monthly-bar-v` / `fmtMonthlyBarV`).
- Series order (`monthlyRowOrder`) is the `#monthly-series` option order and the base for `pickDefaultMonthlySeries`; the timeline rows follow the tree, not this order. Unsegmented rows first, then named segments. Sort keys after that are country (日本 before 海外), then segment (first-seen; issuer `segment_tail` from `/static/monthly_row_order.json`, loaded by `loadMonthlyRowOrderConfig` before Detail tables, ranks those names after other named segments, e.g. 76830 `内アパレル`). Country is not nested inside each segment — every 日本 named segment sorts before any 海外 named segment. Then scope 全店 (0) → 全社 (1) → 既存 (2) → other (3) (`monthlyRowScopeRank`; 全社 is its own bucket, not folded into 全店) → channel 直営+FC → 直営 → FC → unlabeled → metric slot 売上高 → 客数 → 客単価 → 出店 → 退店 → 純増/新設/改装/業態転換 → 店舗数 → その他 (`MONTHLY_METRIC_RANK`) → number before yoy (`monthlyRowUnitRank`) → breakdown rank. Unlabeled 売上高 / 客数 / 客単価 (empty `label.scope`, including unsegmented) sort with 全店 (rank 0). Scope-less 店舗数 / 合計店舗数 and 出店/退店 (no 全店・既存・全社 token) sort in the other-scope bucket (rank 3), not under 全店. Ingest/UI unglue maps `実店舗数` → `実店舗 店舗数` (metric 店舗数, leftover 実店舗). yoy names end with `(前年比)` on `label.display`. There is no gate, stub, or `#monthly-layout-debug` any more (#440).
- Series default (`pickDefaultMonthlySeries`): prefer unsegmented 売上高 yoy where `isAllStoreSalesYoy` (scope 全店 / 全社 / empty, and no country / segment / breakdown); else any such 売上高 yoy; else any `label.series_kind === "all_store"`; else the first ordered row. Country-only rows such as `海外 売上高(前年比)` are not company-wide (#508).
- List `all_store_yoy` / `existing_store_yoy` are not "any matching series". `GET /api/v1/tables` picks via `_headline_yoy_tier` + `_latest_yoy_for_kind`: tier 0 = company-wide `売上高`/`連結売上高` (no `group`/`segment`/`country`/`channel`/`breakdown`); tier 1 = everything else in that kind (segmented EC/オンライン, 客数, 客単価, …). Prefer tier 0; else tier 1; then latest month, then `sort_order` (not element-name lexicographic). Same rule for 既存店. Detail series select is separate (`pickDefaultMonthlySeries`).
- Missing values render as `-` (not a blank cell): list 全店/既存店 YoY via `fmtMonthlyYoyList`, Detail month cells via `fmtMonthlyCell` / server `format_monthly_cell`. Year JSON from `GET /api/v1/tables/{code}/{year}` always has month keys `"1"`…`"12"` with absent months as `null` (0 is a real zero).
- Public `/monthly` (`body.dataset.publicMonthly === "1"`, `monthly-public.js`) is a separate SEO surface: すべて chip, no IR（一時） chip, no 市場/業種 columns, path URLs, 4-digit `<a href>`. This map drives the Basic `/app` monthly tab (`monthlyPublic()` false). Do not treat public-only chrome as `/app` proof. Private TOP loads IR codes via `loadMonthlyIrCodes` → `GET /static/ir_monthly_codes.json` (4-digit set; crawl URLs omitted).
- SPA only reads `/api/v1/tables*`. Write routes (`POST …/ingest`, `PUT …/industry`, values/elements) are MCP/ingest — do not use them in verify.
- Narrow viewports (`@media (max-width:640px)`) keep the timeline name column sticky but narrow it from 18em to 12em (`table.monthly-tl td.tl-name`), and tree indent drops from 1.25em to 0.6em per level (`monthlyIsPhone`).
- TOP `#monthly-tbl` is content-width with `margin-inline:auto` when narrower than the host. The timeline `table.monthly-tl` instead scrolls to the latest month on render, and keeps the scroll position on toggles.
- Deep link codes must match `^[0-9][0-9A-Z]{3}[0-9]$` (`tabs.js` `CODE_RE`); invalid rest is ignored and TOP opens.
