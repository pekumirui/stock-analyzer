# 月次

The monthly tab lists ingested issuer monthly-sales tables with industry chips, then opens a Detail view (series select, year-panel chart, year-stacked tables). It is not a TDnet day calendar.

## Sub-features

- `monthly-list` fills `#monthly-groups` (新着 + industry chips) and TEMP `ゲート（一時）` / `__gate__` + TEMP `IR（一時）` / `__ir__` (private `/app` only; codes from `GET /static/ir_monthly_codes.json`) and `#monthly-tbl` from `GET /api/v1/tables` (list 全店/既存店 YoY prefer company-wide 売上高/連結売上高; #337).
- `monthly-issuer-search` types into `#monthly-sym` (placeholder `銘柄名 or コード`) and fills `#monthly-suggest` from the loaded list (`monthlyRows` / `uniqueMonthlyIssuers`). Typing does not change `#monthly-tbl`. Enter or a suggestion pick commits `monthlySearchApplied` and filters the table (name / code / `industry` / `sector33`). It does not open Detail and does not call `/api/stocks/search`.
- `monthly-detail` opens `#monthly-detail` for a row `data-code` via `GET /api/v1/tables/{code}` then parallel `GET /api/v1/tables/{code}/{year}` for the latest calendar year and up to two prior years.
- `monthly-series` switches `#monthly-series` (default via `pickDefaultMonthlySeries`: unsegmented 売上高 yoy with scope 全店 or empty; else any such 売上高 yoy including segmented 全店; else any `label.series_kind === "all_store"` which is where 全社 can win; else the first ordered row) and redraws `#monthly-chart`.
- `monthly-back` returns to TOP via `#monthly-back` while keeping the selected chip and any committed search filter.
- `monthly-route` persists `#monthly` or `#monthly/{code}` in `location.hash` + `localStorage` `ui.route`; reload/`restoreRoute` reopens TOP or Detail.

## How to get to it (user POV)

- Click `nav button[data-tab="monthly"]`.
- Type a known issuer name, 4-digit / 5-digit code, or industry fragment into `#monthly-sym` and press Enter (or pick `#monthly-suggest`) to filter `#monthly-tbl`. Click a company-name cell to open Detail.
- Click an industry / 新着 / TEMP `ゲート（一時）` / TEMP `IR（一時）` chip in `#monthly-groups`. The 新着 chip is always rendered; if no issuer has `is_new`, selection falls back to the first industry chip but 新着 stays visible. Industry chips appear only for industries present in the list. `ゲート（一時）` and `IR（一時）` render only when `monthlyPublic()` is false (Basic `/app`); public `/monthly` omits both. `__ir__` keeps rows whose `monthlyCode4(code)` is in `/static/ir_monthly_codes.json` (from `config/ir_monthly.json`); empty filter copy is 「IR対象はありません」. A chip click clears the search field and `monthlySearchApplied`.
- Click a company-name cell (`.name`) in `#monthly-tbl` to open Detail.
- Change `#monthly-series` or click a `tr[data-series]` in the year tables.
- Click `#monthly-back` to restore TOP + chip.
- Reload with `#monthly` or `#monthly/{code}` (or the same path in `ui.route`) to restore TOP or Detail.

## Driving it with verify-stock-analyzer

Preconditions:

- Doctor reports `ok`.
- `GET /api/v1/tables` returns a non-empty array (`helpers/capture.py monthly` must not exit 1). If empty, monthly ingest never ran — report that, do not fake rows.

- **Tab.** Click `nav button[data-tab="monthly"]`. `#tab-monthly` is displayed; `#monthly-top` is shown and `#monthly-detail` is `display:none`. List host is `#monthly-list` (holds empty copy or `#monthly-tbl`). Search field is `#monthly-sym` above chips; suggestion box is `#monthly-suggest` (`display:none` until there are hits).
- **List.** `helpers/capture.py monthly` writes `artifacts/monthly/body.json` from `GET /api/v1/tables`. Assert a JSON array; each item has `code` (not `0`-prefix), `industry`, `is_new`, `all_store_yoy` / `existing_store_yoy` (nulls are fine). Those YoY fields are server-picked headline cells (`_latest_yoy_for_kind`): prefer company-wide (no segment / country / channel / breakdown) `売上高` / `連結売上高` over 客数・客単価 or segmented rows; among the same tier take the latest `(year, month)` then lowest `sort_order` (#337). `#monthly-tbl` shows 会社名 / 市場 / 業種 / 月次業種 / 全店(前年比) / 既存店(前年比) (no standalone code column); company-name text is `monthlyCode4(code)` + short name via `fmtMonthlyIssuerLabel`; null YoY cells show `-`.
- **Issuer search.** After the list is loaded, type a known issuer name, code, or industry fragment from that list into `#monthly-sym`. `#monthly-suggest` shows up to 20 rows as 4-digit code + full name. Row count of `#monthly-tbl` must not change while typing. Press Enter or click a suggestion → still `#monthly-top`, `#monthly-detail` stays `display:none`, and `#monthly-tbl` shows only rows whose name, code, `industry`, or `sector33` matches. Click a `.name` cell to open Detail. Clear `#monthly-sym` and press Enter → chip list is restored. Click a chip → search filter clears (`monthlySearchApplied` becomes empty) and the chip list is shown. A query with no suggestion hits keeps `#monthly-suggest` at `display:none`. Enter on that query shows 「該当する発行体はありません」 in `#monthly-list` (not the ingest-empty copy 「登録された月次データはありません」).
- **Detail.** Pass `--code` from the list. Capture also writes years + one year payload (year body includes `elements[].label` with `display` / `breakdown` / `metric_kind`). UI: click a `.name` cell → `#monthly-detail` visible, `#monthly-title` uses `monthlyCode4`, `#monthly-chart` has SVG(s) (one per year panel, bars + value labels), `#monthly-table-wrap` stacks `table.monthly` newest-year-first. `#monthly-back` is bound via `addEventListener` (no inline `onclick`).
- **Proof.** Keep `body.json` (list) and, when `--code` was used, the year artifact(s). If CDP: `ui.png` of Detail or list with header `h1` `株式分析`.
- **Route restore.** After Detail, confirm `location.hash` is `#monthly/{code}`. Reload → Detail for that code (list loads first). `#monthly-back` writes `#monthly`.
- Do **not** call `/api/monthly*`, `#mon-cal`, or `#mon-to-chart` — those are not on this tip.

## Gotchas

- Empty `/api/v1/tables` renders「登録された月次データはありません」— that is empty ingest, or a Cloud Agent build that skipped VPS monthly copy. Not a render bug.
- `#monthly-suggest` is filled only from the loaded monthly list. Do not call `/api/stocks/search` here. A stock without monthly data must not appear. Empty query or no hits hide the box; that is not the ingest-empty copy.
- Committed search (`monthlySearchApplied`) filters `#monthly-tbl` and ignores chips until a chip click or empty Enter clears it. Typing does not write it. Zero hits after Enter is 「該当する発行体はありません」, not the ingest-empty copy.
- Mobile/IME: `compositionend` must refresh suggestions even when no trailing `input` fires. Queries fold via NFKC + hiragana→katakana, so `にとり` and fullwidth `９８４３` hit the same rows as `ニトリ` / `9843`.
- Detail with no years shows「データなし」.
- NEW badge uses `ingested_today` (JST today); 新着 chip window is `MONTHLY_NEW_DAYS` (7) via `is_new`.
- Stored YoY is `yoy_index` (100=flat). YoY display is the stored number. Number cells with a known display unit round half-up (`fmtMonthlyCell` / server `format_monthly_cell`). Units sit on the row name via year-GET `label.display` (`monthly_display_label`, e.g. `受注高（百万円）`); gated stub leaves rebuild the same via `monthlyLayoutLeaf`. Stored `element` stays unit-free; `label.display` may add units. Year-panel chart (`drawMonthlyChart`): one SVG per displayed year, yoy gets a dashed 100 line, bar colors cycle `MONTHLY_YEAR_COLORS[year % 4]`, and each bar shows a value label (`.monthly-bar-v` / `fmtMonthlyBarV`).
- Row order (`monthlyRowOrder`): unsegmented rows first, then named segments. Sort keys after that are country (日本 before 海外), then segment (first-seen; issuer `segment_tail` from `/static/monthly_row_order.json`, loaded by `loadMonthlyRowOrderConfig` before Detail tables, ranks those names after other named segments, e.g. 76830 `内アパレル`). Country is not nested inside each segment — every 日本 named segment sorts before any 海外 named segment. Then scope 全店 (0) → 全社 (1) → 既存 (2) → other (3) (`monthlyRowScopeRank`; 全社 is its own bucket, not folded into 全店) → channel 直営+FC → 直営 → FC → unlabeled → metric slot 売上高 → 客数 → 客単価 → 出店 → 退店 → 純増/新設/改装/業態転換 → 店舗数 → その他 (`MONTHLY_METRIC_RANK`) → number before yoy (`monthlyRowUnitRank`) → breakdown rank. Unlabeled 売上高 / 客数 / 客単価 (empty `label.scope`, including unsegmented) sort with 全店 (rank 0). Scope-less 店舗数 / 合計店舗数 and 出店/退店 (no 全店・既存・全社 token) sort in the other-scope bucket (rank 3), not under 全店. Ingest/UI unglue maps `実店舗数` → `実店舗 店舗数` (metric 店舗数, leftover 実店舗). yoy names end with `(前年比)` on `label.display` / gated `monthlyLayoutLeaf`. Gated issuers only: after that union order, `monthlyTableLayout` / `monthlySegmentGate` (gate counts only years in `monthlyDisplayYears` = latest and up to two prior) add leftover section bars (`tr.monthly-sec`) and `channel | scope | leaf` stubs, and reorder inside a section by channel then scope then metric then number before yoy then breakdown. Breakdown leaves (`label.breakdown`) render as `└ …` with class `monthly-bd` (depth 2 → `monthly-bd-2`). Number and yoy stay separate trees (Belluna: `売上高` → `プロパティ` → `ホテル`, then `売上高(前年比)` → `プロパティ(前年比)` → `ホテル(前年比)`). Non-gated issuers stay a single name column in `monthlyRowOrder` order (name text is `label.display`). TEMP: gated Detail shows `#monthly-layout-debug` to switch 元表（マージ前） (flat single-column union order) vs gated stubs; `sessionStorage` `monthly.layoutMode.debug` (hidden when `monthlyPublic()`).
- Series default (`pickDefaultMonthlySeries`): prefer unsegmented 売上高 yoy where `isAllStoreSalesYoy` (scope 全店 **or empty**); else any such 売上高 yoy; else any `label.series_kind === "all_store"`; else the first ordered row.
- List `all_store_yoy` / `existing_store_yoy` are not "any matching series". `GET /api/v1/tables` picks via `_headline_yoy_tier` + `_latest_yoy_for_kind`: tier 0 = company-wide `売上高`/`連結売上高` (no `group`/`segment`/`country`/`channel`/`breakdown`); tier 1 = everything else in that kind (segmented EC/オンライン, 客数, 客単価, …). Prefer tier 0; else tier 1; then latest month, then `sort_order` (not element-name lexicographic). Same rule for 既存店. Detail series select is separate (`pickDefaultMonthlySeries`).
- Missing values render as `-` (not a blank cell): list 全店/既存店 YoY via `fmtMonthlyYoyList`, Detail month cells via `fmtMonthlyCell` / server `format_monthly_cell`. Year JSON from `GET /api/v1/tables/{code}/{year}` always has month keys `"1"`…`"12"` with absent months as `null` (0 is a real zero).
- Public `/monthly` (`body.dataset.publicMonthly === "1"`, `monthly-public.js`) is a separate SEO surface: すべて chip, no ゲート（一時）/IR（一時）/市場/業種 columns, path URLs, 4-digit `<a href>`. This map drives the Basic `/app` monthly tab (`monthlyPublic()` false). Do not treat public-only chrome as `/app` proof. Private TOP loads IR codes via `loadMonthlyIrCodes` → `GET /static/ir_monthly_codes.json` (4-digit set; crawl URLs omitted).
- SPA only reads `/api/v1/tables*`. Write routes (`POST …/ingest`, `PUT …/industry`, values/elements) are MCP/ingest — do not use them in verify.
- Narrow viewports (`@media (max-width:640px)`) drop the left sticky columns; do not require desktop sticky layout. Gated mobile stubs keep wider scope/leaf (`--stub-sc:4.25em`, `--stub-leaf:8.5em`, scope `nowrap`) so labels like `売上高(前年比)` stay one line.
- TOP `#monthly-tbl` and Detail `table.monthly` are content-width with `margin-inline:auto` when narrower than the host; when they overflow they stay left-aligned so horizontal scroll starts at month 1.
- Deep link codes must match `^[0-9][0-9A-Z]{3}[0-9]$` (`tabs.js` `CODE_RE`); invalid rest is ignored and TOP opens.
