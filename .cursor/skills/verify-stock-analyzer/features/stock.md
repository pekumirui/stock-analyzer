# 銘柄

The 銘柄 tab picks one issuer and shows a common header (name, price, 時価総額, 次回決算) over five sub tabs: 概要 (指標 + the 決算速報 決算表), 株価 (candles, see `chart.md`), ニュース (決算短信 list → the original text in sandboxed iframes with 幅に合わせる / 中 / 原寸 zoom), 株主 (大量保有 + 自己株), and 説明資料 (決算説明資料 list → reconstructed pages; KAB-350). Spec: `docs/DESIGN_stock.md` (KAB-178 #996, KAB-181 #1001, KAB-179 #1002, KAB-267, KAB-350 #1308, KAB-351, KAB-352). Code: `static/js/stock.js`, `static/js/stock-price.js`, `static/js/stock-deck.js`, `static/js/holders.js`, `app/api/stock.py`, `app/api/stock_decks.py`.

## Sub-features

- `stock-tab` shows `#tab-stock` on `nav button[data-tab="stock"]` (second, between 決算速報 and スクリーナー). With no code it sends no request; `#st-head` is `hidden`, every `.st-sub` is hidden, `#st-msg` is hidden, hash `#stock`.
- `stock-search` types into `#st-sym` (placeholder `銘柄名 or コード`) and fills `#st-suggest` from `GET /api/stocks/search?q=` (`4桁コード 銘柄名`). Enter takes the first hit, a click takes that row, Esc closes. Picking keeps the current sub tab (from a news detail it goes to the list; from a deck detail it goes to the 説明資料 list).
- `stock-head` loads `GET /api/stock/{code}/overview` once per code (`showStock`). `#st-title` reads `{name} {code4} / {market} / {sector33}`; `#st-quote` reads `{close} {±change} ({±pct}%) MM/DD 終値 時価総額 N億円` plus `次回決算 MM/DD` (or `未定` when `next_earnings.date` is null; nothing when `next_earnings` is null). No quote → 「株価データなし」. `#st-sym` is set to the issuer name. Then `#st-head` is shown and `#st-tabs.nav-tabs .ftab[data-sub]` gets `.on` on the current sub (folder tab: top+side border, not the filled `.fin-tabs` look).
- `stock-summary` (概要, default) fills `#st-metrics`: PER（予想） `x.x倍` / PBR（実績） `x.xx倍` / 配当利回り（予想） `x.xx%` / ROE（実績） `x.x%` / 自己資本比率 `x.x%`, `–` when the metric is null. Below, `#st-fin-tabs .ftab[data-stfin="cum"|"q"|"prog"|"rev"]` (累計 / 3か月 / 進捗率 / 修正履歴) switch `[data-stfin-wrap]` → `#st-cum-tbl` / `#st-q-tbl` / `#st-prog-tbl` / `#st-rev-tbl`, drawn by earnings.js `renderFin` / `renderProg` / `renderRev` from one `GET /api/earnings/detail/{code}` (no `disclosure_no`, latest filing). A 404 is treated as success with empty rows: 累計 / 3か月 / 進捗率 read `データなし`, 修正履歴 reads `修正履歴なし`. Any other error reads 読み込めませんでした。 in each table.
- `stock-price` (株価) is `features/chart.md`.
- `stock-news` (ニュース) loads `GET /api/stock/{code}/filings` and `GET /api/stock/{code}/decks` once per code into `table#st-news` (日時 `YY/MM/DD HH:MM` / 種類 / 題名), mixed by `submitted_at` / deck `pubdate` (seconds dropped; date-only when there is no time). 種類 is `決算` for annual / semiannual / quarterly and for every deck, else `修正`, plus `訂正` when `is_amendment`. PDF titles end with `（PDF から変換）`. Deck titles are the deck `title`. Rows with documents are `tr.go[data-id]` (`x{id}` XBRL, `p{disclosure_no}` PDF). Deck rows are `tr.go[data-id="d{key}"][data-open="deck"][data-deck="{key}"]` (`key` is the decks API key, `d` + 20 hex). No filings and no decks → `#st-msg` 「ニュースがありません。」. DESIGN_stock.md's `/news` and `#st-news-kinds` are KAB-180 and not in the code.
- `stock-detail` clicks a 短信 `tr.go` → `history.pushState` to `#stock/{code}/news/{id}`, `#st-news-list` hidden, `#st-news-detail` shown: `#st-back` 「← ニュース」, `#st-zoom`, `#st-news-head` (`日時 種類 [訂正] 題名`), `#st-src`, `#st-doc`. An id that matches `NEWS_ID_RE` but is missing from the list → 「書類が見つかりません。」. An id that fails the regex (`NOPE`) is stripped and the list is shown. A deck row does not open this detail: it pushes `#stock/{code}/decks/{key}` and shows the existing deck view (`#st-deck-detail`).
- `stock-doc` puts one `iframe` per document into `#st-doc`, each in `.st-page` (`sandbox="allow-same-origin"`, `scrolling="no"`, title サマリー / 添付資料 / PDF から変換). `src` is the document `url` (`/api/stock/filings/{id}/documents/{seq}` or `/api/stock/pdf/{disclosure_no}`). The iframe grows to its content height. A PDF filing shows `#st-src` 「出典: {attribution}。PDF から変換した原文（画像は出ません）」.
- `stock-zoom` switches `#st-zoom .ftab[data-zoom="fit"|"mid"|"actual"]` (幅に合わせる default / 中 / 原寸) and stores it in `localStorage` `stock.zoom`. `fitStockFrame` scales an iframe wider than `#st-doc` with `transform: scale()` (fit = width, mid = max(fit, 0.75), actual = 1) and sizes `.st-page` to the scaled box. When the document fits (PC), all three look the same.
- `stock-holders` (株主) loads `GET /api/stock/{code}/holders` into `#st-holders-large` / `#st-holders-chart` / `#st-holders-treasury`. Filer names with `filer_edinet_code` call `gotoHolder` → `#holders/{edinet}`. Empty large holders → 「大量保有報告はありません。」. No buyback → 「自己株券買付状況報告書はありません。」.
- `stock-decks` (説明資料, KAB-350) shows `#st-sub-decks`. List `table#st-decks` is 開示日 (`YY/MM/DD`) / 表題 / 読み取り from `GET /api/stock/{code}/decks` (same `stockDecks` cache as ニュース). Status text is `読み取り済み（Nページ）` / `読み取り中` / `読めなかった` / `未読`. Only `status === "done"` rows are `tr.go`. Empty → `#st-msg` 「説明資料はありません。」. A done row `pushState`s `#stock/{code}/decks/{key}?from=stock-decks` and `GET /api/stock/{code}/decks/{key}` into `#st-deck-detail`: `#st-deck-back` 「← 説明資料」, then `#st-deck-body` (title, date, `原本の PDF` when `document.url` is set, reconstruction note, per-page title / summary / SVG charts / table). A 404 JSON `説明資料がありません。` becomes 「説明資料が見つかりません。」. Non-done documents are not clickable on this tab (ニュース still paints every deck row as `tr.go`). A metric whose name contains `為替` is a non-zero-based line (KAB-351; dashed forecast segments, caption `破線・白抜きは予想・計画`). Golden has `briefing_documents=0`, so the list empty copy is the reachable proof; detail and the FX line are `verified-unreachable`.
- `stock-empty` `#st-msg`: 「銘柄が見つかりません。」 (overview 404; `#st-head` stays hidden), 「読み込めませんでした。」, 「ニュースがありません。」, 「説明資料はありません。」.
- `stock-route` writes `#stock/{code}/{sub}` or `#stock/{code}/news/{id}` or `#stock/{code}/decks/{key}` (`ui.route`) via `stockRoutePath()`. Reload restores issuer, sub tab, news detail, and deck detail. `#stock/{code}` opens 概要; an unknown sub falls back to `summary`. A deck key that fails `DECK_KEY_RE` (`^d[0-9a-f]{20}$`, e.g. `NOPE`) is stripped to `#stock/{code}/decks` (the list; `decks` is a known sub). `#st-back` / `#st-deck-back` replace the hash; browser back pops the detail (`popstate`, only while 銘柄 is visible).

## How to get to it (user POV)

- Click `nav button[data-tab="stock"]` (at ≤720px open `#menu-btn` first so `#app-nav` has `.open`).
- Type a name or code into `#st-sym`, then Enter or click a `#st-suggest` row.
- Click 概要 / 株価 / ニュース / 株主 / 説明資料 in `#st-tabs.nav-tabs`, and 累計 / 3か月 / 進捗率 / 修正履歴 in `#st-fin-tabs` (still `.fin-tabs`).
- On ニュース click a 短信 row, then 幅に合わせる / 中 / 原寸 in `#st-zoom`, and 「← ニュース」 or the browser back button. A 決算説明資料 row opens the 説明資料 view, not the news iframe.
- On 説明資料 click a 読み取り済み row, then 「← 説明資料」 or the 説明資料 folder tab (clears the key and returns to the list).
- From other tabs, an issuer name (`gotoChart`) opens 株価.
- Reload with `#stock/{code}`, `#stock/{code}/{sub}`, `#stock/{code}/news/{id}`, or `#stock/{code}/decks/{key}`.

## Driving it with verify-stock-analyzer

Preconditions:

- Doctor reports `ok`.
- ニュース rows need `xbrl_filings` with `xbrl_documents` rows (or `tdnet_pdf_documents` `ok` rows). A box DB copy may have none (every code then reads 「ニュースがありません。」). On a copy this run owns, `DATABASE_URL=sqlite:////abs/copy.db .venv/bin/python jobs/xbrl/xbrl_parse.py parse --from D --to D --dest <xbrl dir with that day's manifest>` fills one day (2026-10-23 from `/mnt/vps/data/xbrl` gave 34 filings / 48 documents). Never run it on a shared DB. Without data, report the document paths as `verified-unreachable`.

- **Capture.** `helpers/capture.py stock --code 72030` writes `artifacts/stock/overview.json` (keys above; golden 72030: close 3094, change +65, `next_earnings` null, per ~11.4, pbr ~1.01; 31160 `quote` null; 39120 has `next_earnings` null), `filings.json` (`{code, name, market, sector33, filings[]}`, each filing `{id, source, submitted_at, title, doc_type, period_type, is_amendment, documents[{seq, part, file_name, url}]}`), `decks.json` (`GET /api/stock/{code}/decks`, `{code, decks[]}`), and `document.html` for the first 短信 document. It prints `filings=N documents=N decks=N` and exits 0 when filings or decks are empty; an unknown code exits 1 with overview 404 `銘柄がありません。`.
- **Document HTTP.** `GET /api/stock/filings/{id}/documents/{seq}` is 200 `text/html` with `Content-Security-Policy` and `ETag` `"<sha256>.s<SANITIZE_VERSION>"`, no `<script>`, and `-webkit-text-size-adjust`. The same request with `If-None-Match` is 304. Unknown filing id or seq → 404 `原文がありません。`. Overview / filings / holders for unknown code `00000` → 404 `銘柄がありません。` (the document URL has no code).
- **Tab.** Reload `#stock` (or a cold open with no issuer): hash `#stock`, header crumbs `トップ > 銘柄` (`#cur-tab` hidden), `#st-head` hidden, no `/api/stock` request. An in-session click of `nav button[data-tab="stock"]` while an issuer is already loaded keeps that code and sub (`selectTab` writes `stockRoutePath()`); it does not unload to the empty search.
- **Search.** Type `トヨタ` into `#st-sym`: `#st-suggest` `3116 トヨタ紡織`, `7203 トヨタ自動車`. Enter → hash `#stock/31160/summary?from=stock`, `ui.route` `stock/31160/summary` (no query), exactly `GET /api/stock/31160/overview` + `GET /api/earnings/detail/31160`, `#st-title` `トヨタ紡織 3116 / プライム / 輸送用機器`, `#st-quote` 「株価データなし」 on golden (no candles either). Reload `#stock/72030/summary`: `#st-quote` `3,094 +65 (+2.15%) 10/16 終値 時価総額 451,569億円` with no 次回決算 (`next_earnings` null). Five `#st-tabs .ftab`: 概要 / 株価 / ニュース / 株主 / 説明資料. `#st-cum-tbl` / `#st-q-tbl` headers include 粗利益; `#st-prog-tbl` / `#st-rev-tbl` do not. Header crumbs are `トップ > 銘柄 > 概要` (`#cur-tab` hidden). Inner-tab clicks add `?from=stock-summary` (株価 / 説明資料) / `stock-price` / `stock-news` / `stock-holders`.
- **Fin tabs.** Click each `[data-stfin]`: only its wrap is visible. Golden 31160 累計 reads `データなし` (no filings in this copy). On a box copy with statements: `#st-cum-tbl` 7 rows, `#st-q-tbl` 12, `#st-prog-tbl` 5, `#st-rev-tbl` 13 (期初 / 修正 / 実績 badges).
- **News list.** Reload `#stock/39120/news`: `#st-news` header 日時 / 種類 / 題名, one `tr.go[data-id="x1"]` `26/10/23 13:00 | 決算 | 2026年12月期　第３四半期決算短信〔日本基準〕(連結)` (copy with the 10/23 parse). A saved deck is another `tr.go[data-open="deck"][data-deck]` with 種類 `決算`, sorted by `pubdate` among the filings. Clicking it pushes `#stock/{code}/decks/{key}` and opens the deck view, not `#stock/{code}/news/...`.
- **Detail.** Click the row → hash `#stock/39120/news/x1?from=stock-news`, `#st-news-head` filled, two iframes サマリー / 添付資料, `scripts` 0 inside. 「← ニュース」 → `#stock/39120/news?from=stock-news-detail`, list visible. Click again then `history.back()` → list again. `#stock/72030/news/zz9999` (id matches `NEWS_ID_RE`) → 「書類が見つかりません。」. `#stock/72030/news/NOPE` fails the regex, rewrites to `#stock/72030/news`, and on golden shows 「ニュースがありません。」. Golden 72030 / 39120 / 31160 have `filings=0`, so the row click is `verified-unreachable` there.
- **Zoom / fit (KAB-175).** At 1400×1000 on a fresh reload of the detail, iframe `style.width` equals `#st-doc.clientWidth` (1337px) and `#st-doc.scrollWidth` equals `clientWidth` (no clip). At 390px mobile, 幅に合わせる gives `scale(0.52…)` (`style.width` 655px, rect 342px = `#st-doc` width). 原寸 / 中 update `localStorage.stock.zoom`.
- **Holders.** `.ftab[data-sub="holders"]` → hash `…/holders?from=` the current sub, one `GET /api/stock/{code}/holders`. `#st-holders-large` has 提出者 / 保有割合 / 差 / 義務発生日 / 保有目的 (`title` on 義務発生日 is 報告義務発生日). A filer name with `filer_edinet_code` is `.clicky` and opens `#holders/{edinet}?from=stock-holders`. No rows → 「大量保有報告はありません。」 (golden 72030 / 18020; the header row is omitted when empty). `#st-holders-treasury` empty copy is 「自己株券買付状況報告書はありません。」.
- **説明資料.** Click `[data-sub="decks"]` from 概要 → hash `#stock/72030/decks?from=stock-summary`, one `GET /api/stock/72030/decks` unless ニュース already filled `stockDecks`. Golden: `#st-msg` 「説明資料はありません。」, `#st-decks` empty. Reload `#stock/72030/decks` (no `from`): 説明資料 `.on`, same empty copy. Reload `#stock/72030/decks/NOPE` → rewrite `#stock/72030/decks`, list (not 概要). A copy that owns `briefing_documents` shows 開示日 / 表題 / 読み取り; only 読み取り済み is `tr.go`. Click it → `GET /api/stock/{code}/decks/{key}`, hash `#stock/{code}/decks/{key}?from=stock-decks`, `#st-deck-back` 「← 説明資料」. Opening the same deck from ニュース uses origin `stock-news`, which `stock-deck-detail` does not allow, so the hash is `#stock/{code}/decks/{key}` with no `?from=`. FX line (metric contains `為替`) is `verified-unreachable` on golden.
- **Empty.** `#stock/31160/news` (no filings and no saved decks in the copy) → 「ニュースがありません。」. `#stock/99990` → hash `#stock/99990/summary`, `#st-head` hidden, `#st-msg` 「銘柄が見つかりません。」. `#stock/72030/bogus` → `#stock/72030/summary`.

## Gotchas

- `#st-tabs` is `.nav-tabs` (folder tabs, KAB-315). `#st-fin-tabs` and `#st-zoom` stay `.fin-tabs` like 決算速報 / PTS. Select by `[data-sub]`, `[data-stfin]`, `[data-zoom]`. At 390px the five `#st-tabs` labels stay on one row (`tests/nonfunctional/test_stock_nav_tabs.py`); `.on` has top+left+right border and a white bottom that meets the content, inactive tabs sit on the bottom line only. `docs/DESIGN_stock.md` still says four labels at 390px — that is product-doc drift, not the SPA.
- There is no `#st-filing` select any more; filings are the ニュース rows.
- The overview is fetched once per code. Switching sub tabs does not refetch it; 概要 fetches `/api/earnings/detail` once per code (`stockFinCode`), ニュース fetches `/filings` and `/decks` once per code (decks share the 説明資料 cache).
- Routing has no `hashchange` handler. Setting `location.hash` to `#stock/...` from another tab (same document) does nothing until reload; `popstate` only routes while `#tab-stock` is visible. Clicking 銘柄 while an issuer is loaded keeps that issuer and sub; reload `#stock` for the empty search.
- The iframes are `sandbox="allow-same-origin"` without `allow-scripts`; links inside do nothing. Measuring height needs same-origin access, so do not fetch documents from another origin.
- A changed sanitizer without a `SANITIZE_VERSION` bump keeps returning 304 with the old HTML.
- `fitStockFrame` re-measures on load (and the next animation frame), zoom change, window width change, and `#st-doc` width change (`ResizeObserver`). The observer covers the PC first paint where the page scrollbar appears after the first measure and used to clip ~15px (KAB-175, fixed in #988). Height-only resize (mobile address bar) does not re-measure.
- EDINET 有報 are not listed; only TDnet XBRL and converted PDFs.
