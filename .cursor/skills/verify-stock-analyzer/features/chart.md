# 銘柄 › 株価

The 株価 sub tab of 銘柄 draws adjusted daily, weekly, monthly, or yearly candles with MAs, a volume / turnover overlay on the same 440px pane, an optional 営業利益 pane (`#chart-fund`, +120px → 560px), 対TOPIX on that same pane (`#rel` adds no height), and post-earnings α for the issuer picked in 銘柄. It was the チャート tab until KAB-181 (#1001); there is no `#tab-chart`, `#sym`, `#suggest`, `#chart-title`, or 表示 button any more. Since KAB-300 the chart is the shared module `static/js/chart-core.js` (also used by 決算速報 `#e-chart`); `static/js/stock-price.js` wires the controls. The library is served from `static/vendor/lightweight-charts-5.2.1/` (no CDN).

## Sub-features

- `price-open` shows `#st-sub-price` on `#st-tabs .ftab[data-sub="price"]` (or route `#stock/{code}/price`). `showStockPrice` runs `loadChart()` only when the drawn code (`stockPriceCode`) differs, so reopening the tab for the same issuer sends nothing.
- `price-candles` fills `#chart` from `/api/chart/{code}`, which returns daily columns `{t,o,h,l,c,v,tv,earnings_dates,monthly_publications}` once per code. `createStockChart($("#chart"), {height: 440})` overwrites the markup `height:520px`. There is one price pane. Volume or turnover is a histogram overlay on that pane (`priceScaleId: "vol"`, bottom 20%, no axis and no `.chart-unit` `(万株)`; the legend still uses `chartQty` `万株`). Weekly / monthly bars, MAs and the relative line are built in the browser. `.chart-ohlc` sits above the plot (KAB-314; sibling before `#chart` / `#e-chart`): date + 始/高/安/終 + change vs the previous bar of the crosshair (or the last bar). No 日足/週足/月足/年足 in that row. `.chart-legend` overlays sit at the top-left of each pane (KAB-311): the candle pane shows MA values in their line colors and, with `#chart-band`, the PER band values. Horizontal touch sets `touch-action: pan-y` and moves the crosshair; pane `enableResize` is false. A failed request (this route 404s `no data` when there are no rows; `api()` throws) → `#chart-msg` 「読み込めませんでした。」. Empty `t` on HTTP 200 → 「株価データなし」; `/api/chart` does not emit that 200 today. `#st-quote` 「株価データなし」 is the overview path (`quote` null), not the chart.
- `price-controls` `#tf` (`.fin-tabs` buttons `[data-tf]` `D` 日足 / `W` 週足 / `M` 月足 / `Y` 年足, `.on` on the chosen one; default `D`. There are no period buttons and no 自動 since KAB-306), `#mas` (`change`), `#chart-sub` (`v` 出来高 / `tv` 売買代金), `#chart-hl` 高安値 (default on), `#chart-log`. None of them sends a request. `#tf` / `#chart-sub` / `#chart-fund` / `#chart-hl` / `#chart-band` / `#chart-log` persist in `localStorage['chart.view']` (`loadChartView` / `saveChartView` in `stock-price.js`). `#rel` and `#mas` do not.
- `price-fund` `#chart-fund` (blank option label `業績なし` / `op` 営業利益 / `per` 予想PER / `mcop` 時価総額÷営業利益) is the only extra pane and grows `#chart` by 120px (`style.height` 440px → 560px). `.chart-unit` is `(百万円)` on 営業利益 when the series max is at least 1e6 yen. `#chart-band` draws three dashed `PER n倍` step lines on the candle pane (n = 10/50/90% points of the issuer's 予想PER). Both come from `fund` / `mc` in the same `/api/chart/{code}` body (no extra request) and persist in `chart.view`. The legend gets a third line (`営業利益 四半期 … 12か月 …` / `予想PER 12.1倍` / `時価総額÷営業利益 12.2倍`). On the golden DB, 72030 has no 12か月 value from 2025-08 to 2025-11 (the 2024 1Q filing is outside the golden data); 80010 (1→5 split on 2025-12-29) shows a PER line without a jump at the split.
- `price-nav` (KAB-306) the chart itself does not move: wheel, drag and pinch on `#chart` do nothing (on a phone a vertical swipe scrolls the page). The period is set by `.chart-nav` (canvas, 44px, the sibling right after `#chart`): drag inside the window to move it, drag either edge to resize (min 10 trading days), press outside to jump the window there. The chart follows while dragging and always fits the period to the width (also after a resize). Opening an issuer or switching `#tf` to 日足 shows the latest 1 calendar year of daily bars (the whole series when it is shorter than a year). Switching to 週足 / 月足 / 年足 shows the latest bars of that kind, as many as fit at 6px each (min 20). Widening the window does not change the bar kind. `#chart-hl` puts `M/D value` labels (`YY/M/D` when the period is over a year) on swing highs (above) and lows (below); labels that would stick out of the chart edges drop the date or are skipped.
- `price-rel` `#rel` hides the candles and draws 株価 and TOPIX on the same pane (indexed to 100 at the visible window start) from `GET /api/topix` (fetched once per page). It does not add a pane or height (fund+rel stays 560px / 2 panes).
- `price-perf` fills `#perf-tbl` (発表日 / +1d / +5d / +20d / +60d / 現在まで; each period cell is 2-tier: return on top, `(α)` vs TOPIX in the `.g` line below, KAB-608) from `/api/earnings-performance/{code}`, at most 12 rows.
- `price-events` `.evt-toggles` inside `#st-sub-price` has `input[data-evt="earnings"]` 決算発表 and `input[data-evt="monthly"]` 月次発表 (`fillEventToggles`). Markers come from chart JSON `earnings_dates` / `monthly_publications` when that box is on; on/off is kept in `localStorage.chartEventOverlays`. Golden 72030 has `earnings_dates` and empty `monthly_publications`, so 月次発表 adds no marks.
- `price-goto` `gotoChart(code)` from 決算速報 (`#e-chart-title .clicky`), スクリーナー / PTS / ランキング / 大量保有報告書 (issuer name `.clicky`; the 保有者 name is `gotoHolder`), サプライ (`#supply-chart-link` 「株価を開く」) opens 銘柄 with 株価 `.on`, hash `#stock/{code}/price?from=` when the caller screen is in the exact allow-list (`earnings`, `screener`, `ranking`, `ranking-pts`, `supply`, `holders`, `holders-detail`, `stock`, `stock-summary`, `stock-financials`, `stock-news`, `stock-holders`). `stock-news-detail` and `stock-deck-detail` are dropped. Inner-tab 株価 from 業績詳細 is `#stock/{code}/price?from=stock-financials`. A reload of `#stock/{code}/price` has no query. `ui.route` stores the path only.
- `price-route` `#stock/{code}/price` restores it on reload. Old `#chart/{code}` or `ui.route` `chart/{code}` is read as `stock/{code}/price`; bare `#chart` → `#stock`.

## How to get to it (user POV)

- Pick an issuer from the header search (`#sym-btn` → `#sym-q`) and click 株価 in `#st-tabs`.
- Click an issuer name on 決算速報 (chart title), スクリーナー, PTS, ランキング, or 「株価を開く」 on a listed サプライ company.
- Click a `#tf` button, drag the window in `.chart-nav`, change `#tf` / `#chart-sub`, tick `#chart-log` / `#rel`, or edit `#mas` and dispatch `change` (blur). Enter on `#mas` does not fire `change` (the field is not in a form).
- Tick `.evt-toggles` 決算発表 / 月次発表.
- Reload with `#stock/{code}/price` (or an old `#chart/{code}` bookmark).

## Driving it with verify-stock-analyzer

Preconditions:

- Doctor reports `ok`.
- A known code exists; doctor search for トヨタ should yield `72030` or similar.

- **Capture.** `helpers/capture.py chart --code 72030` writes `artifacts/chart/body.json` (`t` length > 0, `o`/`h`/`l`/`c` already from `adj_*`, `v`, `tv`, `mc`, `earnings_dates`, `monthly_publications` (golden 72030 `[]`), `fund` = `{t, eps, op_q, op_ttm}`) and `performance.json` (a list, may be empty; still 200).
- **Open.** Clear `localStorage['chart.view']` (or set `#chart-fund` to the blank 業績なし option and dispatch `change`) then reload `#stock/72030/price` (golden DB has candles; 31160 does not — see Gotchas). Hash `#stock/72030/price`, `#st-title` `トヨタ自動車 7203 / プライム / 輸送用機器`, `#chart` `style.height` `440px`, one pane, `#chart canvas` present, `#chart-msg` hidden/empty, requests `GET /api/chart/72030` + `GET /api/earnings-performance/72030`, `#tf .on` is `日足`, `#chart-fund` shows `業績なし`, `#st-sub-price .evt-toggles` has 決算発表 and 月次発表, `#perf-tbl` headers are 発表日 / +1d / +5d / +20d / +60d / 現在まで (each period header also shows `(α)` in `.g`), and the 日足 visible range runs from the first session on or after one year before the last daily bar through that last bar (a shorter series shows every bar). It does not follow width/6. No button whose label contains 表示. A leftover `chart.view` `fund=op` opens at `560px` with two panes — that is restore, not a broken default.
- **404.** Cold reload `#stock/31160/price`: overview 200, `#st-quote` 「株価データなし」, chart HTTP 404 `no data`, `#chart-msg` 「読み込めませんでした。」, no canvas from that response. A same-document search / `gotoChart` / inner-tab open of 31160 after a drawn 72030 leaves the previous canvas and keeps `#tf` / `#rel` / `#chart-fund`; do not treat leftover 72030 candles as 31160 data. Assigning `location.hash` alone does not switch issuers (no `hashchange` handler). Click 概要 then 株価: both price requests fire again (`stockPriceCode` was cleared).
- **Controls.** On the 72030 draw, click `#tf [data-tf="W"]` (range jumps to the latest ≈ width/6 weeks), set `#mas` to `25` and dispatch `change` (Enter alone leaves the legend on MA50/150/200), `#chart-sub` to `tv` + `change`: no new `/api/` request. Set `#chart-fund` to `op` → height `560px`, two panes, `.chart-unit` `(百万円)`. Tick `#rel` → one `GET /api/topix` (only the first time), still `560px` / two panes. Click `[data-tf="Y"]` → yearly bars (3 on the golden DB) and no MA lines (50/150/200 days are under 2 years).
- **Period bar.** Wheel over `#chart`: `stockChart.chart.timeScale().getVisibleRange()` does not change. Drag the window in `.chart-nav` left: the range moves by the same share of the history. Drag the left edge left to the start → still 日足, just thinner.
- **Reopen.** On that successful 72030 draw, click 概要 then 株価 again: no `/api/chart` or `/api/earnings-performance`. Opening another code and coming back within 10 minutes reuses the in-memory daily data (no `/api/chart`); after that the browser revalidates with `If-None-Match` (304).
- **Old route.** Reload on `#chart/72030` → hash `#stock/72030/price`, `#st-title` `トヨタ自動車 7203 / プライム / 輸送用機器`, only `#st-sub-price` visible. `localStorage` `ui.route=chart/39120` with no hash → `#stock/39120/price`.
- **gotoChart.** From each caller above: `#tab-stock` shown (no `nav button[data-tab="stock"]`), 株価 `.on`, hash `#stock/{code}/price?from=…`, `GET /api/stock/{code}/overview` and `GET /api/earnings-performance/{code}`. `GET /api/chart/{code}` is skipped when that code was loaded in the last 10 minutes (including 決算速報 `#e-chart`). A second `gotoChart` of the same code sends nothing.
- **Proof.** Keep `body.json` and (if CDP) a screenshot with `#chart` tall enough to show candles and the 銘柄 header.

## Gotchas

- Prices in the chart are **adjusted** (`adj_*`). Do not assert raw `close` against the canvas; the header `#st-quote` uses the overview `quote.close`.
- Codes are 5 characters (`72030`). Labels show the first 4; the API still uses 5.
- `/api/chart/{code}` with no rows is HTTP 404 `no data`, so `#chart-msg` is 「読み込めませんでした。」 (31160 on the golden DB). Do not expect 「株価データなし」 on the chart for that 404; that copy is the empty-candles 200 branch, which this API does not emit. Overview `#st-quote` 「株価データなし」 is a different field (`quote` null).
- `#tf`, `#mas`, `#chart-sub`, `#chart-fund`, `#chart-hl`, `#chart-band`, `#chart-log`, `#rel` keep their values across issuers; a new issuer is drawn with the current controls and the latest bars. `#tf` / `#chart-sub` / `#chart-fund` / `#chart-hl` / `#chart-band` / `#chart-log` also survive a reload via `chart.view`. Assert 440px only after that blob is missing or `fund` is blank.
- Setting `.value` from a script does not redraw; dispatch `change` like the browser does.
- `#tf` defaults to `D`. `W`, `M`, `Y` are resampled in the browser (`chartBars`); MA windows scale down (÷5 / ÷20 / ÷250) and are dropped under 2 bars.
- `#perf-tbl` shows at most 12 rows even if the API returns more.
